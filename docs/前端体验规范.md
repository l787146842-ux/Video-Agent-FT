# 前端体验规范（强制约束）

> 来源：宪法 v2 前端条款迁移（2026-08-13 宪法 v3 拆分）。本文件是**品牌 / 视觉 / 交互细节**的唯一家；
> 与宪法 §3.1（体验基线不退化）、§3.2（前端工程）同为前端强制约束，前端工程按批次执行。

## 一、品牌与视觉

- 品牌名正式为「**飞天**」：毛笔行楷笔形（Xingkai/华文行楷/KaiTi 字体栈）、白色、22px、垂直居中、不加人工斜切；**禁止**使用旧品牌名
- 顶部导航按钮（影视工作台/画布/API 配置）**绝对居中**，两侧内容增减不得使其偏移

## 二、交互规范（强制）

| 项 | 规范 |
|---|---|
| 发送/停止键 | Agent 运行时**只保留停止键**；发送键仅空闲态显示 |
| 交互确认卡片 | 亮橙色系（主色 `#fb923c`，边框 `rgba(251,146,60,0.6)`、底色 0.12），亮度档对齐阶段完成卡翡翠绿（`rgba(52,211,153,0.3)`）；**禁止** box-shadow/发光 |
| 阶段完成卡片 | 标题+操作数徽标，**可展开**（默认展开）：正文=本轮概述（确认文案）+执行清单；点击头部折叠/展开（814G1 以用户调教版为准，取代 814F6「不显示正文」）；**确认文案与模型正文判重**（正文已含同样句子时卡片只留执行清单）；历史消息同样可展开（暂停点回看不丢失） |
| 闸机拦截警告 | **结构化来源标注 chips**（「平台」/「Skill『xxx』」徽标+规则描述，数据源 trace.gates）；「本次放行」按钮按**结构化判定**挂载（不依赖文案措辞）；纯文本 warnings 仅承载非闸机类系统通知 |
| 过程时间线 | 运行中与完成后**同条目/同顺序/同耗时**（814G2）：规划轮、工具、执行器子步骤（子挂父后）；运行中条目走秒计时；刷新后从 trace 重建不丢；连续规划条目合并为「规划 N 轮 · 累计耗时」单条（明细点击展开）；**职责切分：status 栏 = 当前正在做的一件事，时间线 = 本轮已发生的全部账目** |
| 深度思考视窗 | 定高 + `overflow-y:auto` 可滚轮回看上文；自动跟随仅当用户停在底部（814G9） |
| 故事板微调框 | 仅悬停**草稿卡片** 300ms 后缓缓浮现（CSS transition，禁止瞬时弹出）；输入仅针对该卡片；列表其他位置不弹 |
| 分组卡片 | 左上标题只显示名字（显示层只剥容器类型前缀 `Element_`/`Shot_`/`Audio_` 三个，其余原样；数据层 = 容器 ID 约定 = 类型前缀+模型原名，写口幂等补前缀、无词表翻译，2026-09-17 裁决对齐 flova）；右上徽标：关键元素无（2026-09-17 裁决：类别标识退役，存量 badgeLabel 只读透传不显示）、分镜=固定「分镜」、音频=时段（双击可编辑） |
| 上下文用量 | 纯圆圈（无进度条）+ K 数字 |
| 排队引导 | 点「引导」后该条**原位转圈圈**等待接管，禁止顶部 toast 提醒；「引导」**不打断**当前任务：移队首并登记轮间注入，后端在当前操作完成后的最近轮边界注入（R3 语义，2026-08-15 修订） |
| Skill 消息 | text 与 skillBlocks[0] 相同（trim 后）时仅渲染紫色图块，不重复文字 |
| @ 面板 | 宽 600px/高 560px；网格式卡片（缩略图在上名称在下）；顶部搜索框必须可点击聚焦；关键元素/分镜/音频页签 + 参考栏素材分区；**@ 故事板素材不自动加入参考素材栏** |
| 视频素材 | @ 弹层/提示词 chip/参考素材栏均显示**首帧缩略图 + 左上角 ▶ 角标** |
| 参考图上传 | 分镜面板不设数量上限 |
| 参数栏下拉 | 宽度跟随所选文字（`field-sizing: content`，含箭头占位） |

## 三、前端工程

- 前端工程约束（唯一前端 `src/web` SolidJS SPA、构建产物 `static/dist`、禁复活旧 studio 页面、类型契约 `scripts/gen_api_types.py --check`）唯一家 = **宪法 §3.2**，本文件不复述（下方台账 #18/#19 仅登记验证映射）。
- 界面文案**中文唯一**（2026-08-17 九轮 D2 裁决）：各组件（含 docs 族）硬编码中文合法、豁免 t() 抽取；`lib/locale.ts` 的 t() 基建继续服务 SSE 状态 key 与错误码翻译（`agent.*`/`rp.streaming.*` 等），不做全界面多语言化
- **桌面优先，无移动端承诺**（九轮观察项明示）：全前端无 @media 响应式断点系有意定位（Agent 工作台桌面场景），不视为缺陷；未来若承诺移动端需另行立项并补断点规范
