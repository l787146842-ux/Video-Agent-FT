#### ③ 发暂停卡纠结 34 秒 —— 根因 = 无处安放的第 2~5 个问题

**实测**：turn2 step2 为「怎么问这一个问题」花了 **8 段思考增量、2740 字、34.3 秒**（conv-main seq 31–36）。

### Q3 单选的锅 + 两条真缺陷

#### ① 为什么是单选 —— 模型的选择，且在现形态下是**正确的**选择

`multi_select=false`（默认值），推理见 conv-main seq 34：「其实更稳妥：**单选**，选项为几套预设组合 + 自定义。这样不会矛盾。」以及 seq 33：「风险是用户全选导致矛盾。」

**病根是 Q2③ 的缺少 `questions` 层**，不是模型保守。

#### ② 详细描述没进记录 —— 确认属实

`ConfirmActions.tsx:67-69` 的 `valueFor()` 返回 `o.value || label` —— **`description` 只用于显示，发送时被丢掉**。

**与 dsh 的关系**：dsh 的 `answers.selected` 同样只回标签（`dsh-user-questions/lib/types/types.d.ts:46-53`），差别在 dsh 有 `custom` 槽承载自由文本。**本项目与 dsh 在"回携标签"这点上一致**；差距在**回看显示**：`AnsweredOptions.tsx:33-41` 只渲染 `opt.label`，**不渲染 `opt.description`**（而 description 明明随 `confirmOptions` 一起落盘了，`state.sqlite3` 里查得到）。

#### ③ 二向箔答不了 —— 真缺陷，后果比浪费 token 严重

模型把二向箔显名降级塞进 `detail`：

```

```

`detail` 是**纯展示文本、不是可选项**（`document_tools.py:129-132` 明写「这段文本只作说明，不会变成可选项」）→ **用户点卡片时，结构上无法对二向箔表态**。

**后果链**：

```

  → 模型 seq 46「二向箔显名问题我还没得到回复（用户只选了选项）」

```

`state.sqlite3` 落盘取证：`制片规格.md` 该行确实在。

**一个用户从未表态的创作决策被写成了既定规格** —— 正是 `protocol.md:13` 判据④「未确认的创作选择不得写成既定规格，须先向用户确认或标作待定」要防的事。**根因是工具形态让用户答不了，不是模型不守规矩。**

resp = await child.handle_message(base_task, child_ctx, on_event=child_on_event)

### Q5「尚未落入规格文档的新决定：输出语言…」为什么多余 —— 规则**强制**写出来的

**时间线**：turn2（15:23:50）派 `script_analyze` 时，`制片规格.md` **还不存在**（该项目 `documents` 在 turn2 的状态 JSON 里只有 `执行铁律.md`；规格是 turn3 15:27:59 才由父 `document_write` 建的）。

**缺陷在段②的判据口径**：判据是相对**「规格文档」这一个载体**定义的，而不是相对**「这个子代理用不用得上」**定义的。于是：

**规则"按设计工作"了，这正是问题**：产出内容的时机只取决于「决定新不新」，完全无法判断「子代理要不要」。

批3 的动机是对的（2222 实测模型必猜错一次中文名，花 3.5s + 一次失败往返），**代价是把平台 UI 词汇喂进了模型上下文**，于是模型在任务书与对用户正文里都用了这个词。同一批还把它写进子代理任务头（`subagent.py:348-349`：「本次委派阶段：{label}」）。

#### ②「制片规格已写入…剧本为已上传的…本阶段无新增未落盘决定」= 强制槽位被填成空声明

模型**明确决定过只写 ①**（seq 50）：「任务书两段：①一句目标；②尚未落入规格文档的新决定——**没有新的。那就只写①**，并说明执行依据。」

但它还是写了两样东西：

1. **指针 + 规格内容复述**：「制片规格已写入「制片规格.md」（**16:9、约 4 分钟、电影级写实科幻冷调、中文台词+中文提示词、角色按原著气质写实设计**），剧本为已上传的《三体简短版.md》。」——括号内那串是**规格内容的第二份复述**，而 `SUBAGENT_POLICY:39` 与 `RunSubagentInput.task` 的 description **两处都明写「既有内容不用复述（子代理自看工作台、自读文档）」**。
2. **空声明**：「本阶段无新增未落盘决定。」

**诱导源 = 段② 是一个"必须存在"的槽位**：模型不会把它留空，它会写一句「无新决定」来交代槽位，并顺手补上「规格在哪、剧本在哪」——因为它认为子代理需要这个上下文才敢开工。**判据「必须写②」与禁忌「别复述既有内容」在这句话里正面撞车，模型选了前者。**

**另外批C 没治住的那一半**：段① 里模型写了「**供后续镜头设计与设定图生成使用**」—— 这正是批C 从策略里删掉的**「下游用途」**。删掉槽位不等于删掉内容：`SKILL.md:25` 自己写着依赖图（`4→3`）、`:19`「生成所有 key_element 设定图」，**Skill 本身就把下游关系交给模型了**。批C 拔了槽，Skill 还在供料。
