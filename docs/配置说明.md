# 配置说明

> 本文档梳理本项目全部配置源的**权威关系与加载优先级**（计划书 P1-7）。
> 原则：每类配置只有一个权威源；环境变量仅用于覆盖/部署差异，不承担业务数据。

## 配置源总览

| 配置源 | 角色 | 是否入库 | 读/写方 |
|---|---|---|---|
| 根目录 `.env`（模板 `.env.example`） | **运行参数**：端口、画布地址、记忆后端、安全开关等 | 否（gitignore） | `config.py::load_dotenv()` 启动时加载 → `settings` |
| `API/.env` | **第三方 API Key 唯一存放地** | 否（gitignore 第 3 行） | `web/provider_config.py` 读取；api-settings 页面写入（带消毒与锁） |
| `data/api_providers.json` | **供应商列表与模型配置的权威源** | 是 | `provider_config.load_merged_providers()`；api-settings 页面读写 |
| `data/canvas_integration.json` | 画布版本漂移记录 | 否（data/ gitignore） | `canvas_adapter.check_version_drift()` 自动维护 |
| `prompts/**` | 外置 Prompt（Rule 6） | 是 | `utils/prompts.py::load_prompt()` |
| `workspace/state.json` | 项目状态持久化（StateManager，Rule 3） | 否 | 仅 StateManager 可写 |

## API Key 解析优先级

`provider_config._resolve_api_key()` 按以下顺序取第一个非空值：

1. **进程环境变量**（如 `OPENAI_API_KEY`）
2. **本项目 `API/.env`**
3. **画布 `API/.env`**（仅当设置了 `CANVAS_ENV_FILE` 且该 provider 来源于画布）

> 计划书曾提到 `agent-config.json` / `canvases.json` / `appinfo.json` 三个文件——
> 经核实现状：它们**不属于本项目**，是画布侧的数据文件。本项目只通过 HTTP
> 与其交互（`GET /api/providers` 合并供应商、`GET /api/app-info` 探测版本、
> `/api/canvases` 读写画布），从不直接读其本地文件（Rule 7）。

## 供应商配置的合并规则

最终生效的 provider 列表 = **本项目 `data/api_providers.json`** 与
**画布 `GET /api/providers`**（HTTP，带缓存，TTL=`CANVAS_HEALTH_CACHE_SECONDS`）合并，
同 id 时以本项目条目优先。画布离线时静默降级为仅本地列表。

可选增强（默认关闭）：设置 `CANVAS_PROVIDERS_FILE` / `CANVAS_ENV_FILE` 直接指向画布的
本地配置文件，用于离线场景；默认留空，全部走 HTTP。

## 环境变量清单（根目录 .env）

完整清单以 `.env.example` 为准，关键字段：

| 变量 | 默认 | 说明 |
|---|---|---|
| `PORT` / `HOST` | `8080` / `127.0.0.1` | 服务监听（勿与画布 3000 冲突） |
| `ENVIRONMENT` / `API_KEY` | `development` / 空 | production 时 `/api/*` 强制 `X-API-Key` 校验 |
| `CANVAS_BASE_URL` | `http://127.0.0.1:3000` | 画布地址 |
| `CANVAS_ENABLED` | `true` | 关闭后所有画布功能降级 |
| `AGENT_MAX_STEPS` | `6` | Agent 多步循环上限（Rule 2） |
| `MEMORY_ENABLED` / `MEMORY_VECTOR_BACKEND` | `true` / `chromadb` | 记忆系统；未装 chromadb 自动降级 JSON 检索 |
| `STATE_BACKEND` | `json` | `json` / `sqlite`（sqlite 首次启动自动迁移） |
| `STORAGE_BACKEND` | `local` | `local` / `s3` |

代码中禁止硬编码可调参数（ARCHITECTURE_RULES §二）：新增可调项一律加到
`config.py::Settings` 并在此表登记。

## 运行时数据（均不入库）

- `workspace/`：项目状态、生成资产（StateService/StateManager 管理）
- `data/memory/fallback.json`：记忆系统 JSON 降级存储
- `data/skills/*.md`：技能文档（可在 UI 内新建，写入即落盘）
- `logs/`：loguru 日志（按日滚动）

## 修改配置的注意事项

1. **密钥只进 `API/.env`**，不要写进根 `.env`（根 `.env` 可能被提交模板化）；
2. 增删供应商改 `data/api_providers.json`（或用 api-settings 页面），**不要**改代码默认值；
3. 对接新版画布后：启动日志若出现版本漂移 warning，按
   [tests/fixtures/canvas/README.md](../tests/fixtures/canvas/README.md) 刷新契约夹具并跑契约测试。
