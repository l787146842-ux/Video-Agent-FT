## 三、头号发现（P0，A 报告独有）：模型 fallback 链 NameError

**位置**：`src/video_agent/web/chat_service.py` L495

```python
# L483：只解包了 model
next_model = candidates[idx + 1][1]
...
# L495：next_provider 从未定义（全仓库 grep 确认仅此一处引用，无任何定义点）
AgentTracer.get_instance().record_fallback(next_provider, next_model)
```

**性质**：except 分支内必抛 `NameError`。触发条件四项同立且恰是产品推荐配置：fallback 默认开（宪法 §4）+ 主模型瞬时故障（retryable=True）+ 本轮未执行操作 + 多供应商同模型候选 >1。

**双路径症状**：
- **任务式**（主前端 startAgentTask）：`_run_agent_task` 兜底捕获 → 用户先见「模型已切换重试…」状态条，紧跟内部错误外泄气泡「服务端异常： name 'next_provider' is not defined」，fallback 完全失效；
- **SSE 直连**（`/agent/chat/stream`）：worker 静默死亡、无终态事件，前端**永久卡在切换提示**直到断连。

**测试盲区**：test_nine_fixes 直调 `_apply_event`、test_b10_metrics 直调 `record_fallback`、test_config_fallback_switch 只测开关——`_real_stream` 的 fallback except 分支**零覆盖**。pytest 1106 全绿也照不出此缺陷。
