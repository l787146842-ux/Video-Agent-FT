## 改写语义（唯一口径）

| 幻影词 | 改写为 |
|---|---|
| script_analyze | read_uploaded_doc + 模型自行分析（无独立分析工具） |
| storyboard_*_三件套 | storyboard_create_group / storyboard_add_draft / storyboard_patch_draft |
| write_media_prompt | 提示词由模型撰写，经 storyboard_patch_draft 写入草稿，生成时作为 image_generate / generate_video 入参 |
| audio_generate | 由系统音频生成通道按 audio_layers 配置产出（无需工具调用）；text_to_instrumental / text_to_narration 渠道模式名保留 |
| video_assembler | 时间线组装与导出由用户在工作台操作，Agent 引导即可（无对应工具调用） |
| bind_asset | 经 storyboard_patch_draft 登记到草稿参考字段（生成时系统自动挂接） |
| reply_to_user | 直接回复文本告知；暂停语境改为 workflow_pause |
