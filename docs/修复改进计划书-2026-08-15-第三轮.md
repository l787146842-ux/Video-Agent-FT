   配快照测试锁语义；13.8 台账登记；预算脚本复跑。
2. **N3**：`flow_gates.pause_message` 拼接归一化（reasons 尾句号去重，单点修复覆盖全部调用路径 G4）；回归断言文案不含「。。」。

### B2 UI 修复与重做（浏览器目测批，暗/亮双主题）

1. **U3（G4 全局化）**：tokens.css 增加 button 基线重置（`button { background: transparent; border: none; color: inherit; font: inherit; }`，仿 preflight 根因修复），逐页目测确认无按钮因此退化；个别确需 UA 样式的控件显式声明。白块即愈，同时清偿同类潜在漏网点。
2. **U4**：SkillPicker outside-click 判定改 `e.composedPath().includes(ref)`（派发瞬间路径，不受重渲染脱 DOM 影响）；并加「confirmingId 非空时不关面板」双保险；e2e 或目测钉死「点删除→面板仍在→确认条可见」。
3. **N4**：`.studio-container` 与 `.studio-header` min-width 统一提至 1120px（窄屏整页横向滚动兜底已有）；目测 947/1087/1280 三断点无重叠；台账 814F6 行补注。
4. **N5**：QueuedMessagesBar 加 effect——条目不在队列即清 guidedId；done/出队后 spinner 终止。
5. **U5 API 配置页视觉重做**（保留 SPA 原生实现，仅重做视觉层）：
   - 卡片头行：名称 + 标识(id) + 协议下拉（空值占位「请选择协议」）+ 启用开关 + 删除（危险色靠右）；

   - 卡尾操作右对齐：拉取模型 / 测试连接（次级按钮）；顶栏「添加供应商」次级 +「保存全部」主按钮右对齐；
   - 间距/圆角/线色全走 tokens.css 变量；目测暗/亮双主题 + 与工作台整体节奏对照截图。

### B3 卫生与观测

1. **N6**：trace 记录增 `llm_calls` 字段；`tracer.metrics` 平均耗时仅聚合 `llm_calls>0`（旧 trace 缺字段回落全量，兼容）；运行成本卡 UI 标注口径「仅含模型调用轮」。
