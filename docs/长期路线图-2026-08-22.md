## 长期项清单

每项含：来源审核编号、现状、目标态、触发条件/优先级、风险。

### L1 · 评测双轨制（capability → regression + pass^k）
- **来源**：G 类；对标差距维度 7（门禁与评测）。
- **现状**：`scripts/run_eval_pipeline.py` 已有黄金语料雏形，闸机靠黄金语料手工校准；
  无 capability/regression 分轨，无一致性指标。
- **目标态**：能力评测爬坡 → 毕业转回归评测的双轨模型；三类评分器组合 +
  pass^k 一致性指标；「改任何提示词/闸机先过 eval」成为迭代纪律。
- **触发条件/优先级**：闸机阈值调整频率上升或出现一次误杀/漏放争议时启动；
  长期项中优先级最高（评测驱动是其余各项的安全网）。
- **风险**：语料维护成本反噬；需防「为过评测而改提示词」的指标漂移。

### L2 · 多级渐进压缩管线 + append-only 转录 + 缓存命中率指标
- **来源**：G 类；对标差距维度 2（上下文治理）；Claude 五级压缩对标结论。
- **现状**：已有轮内 compaction（旧轮折叠摘要、图片剥离，§13.11 C3）与
  session_compact 模板；无「工具结果限额 → 轻裁剪 → microcompact → 全量摘要」
  分级序列；转录非只增不删；前缀缓存排序已有但无命中率观测。
- **目标态**：分级压缩从轻到重逐级触发；压缩只加边界+摘要事件、原文可回放；
  缓存命中率成为一级观测指标。
- **触发条件/优先级**：单次会话出现压缩质量劣化或 token 预算告警时启动；高。
- **风险**：压缩丢关键创作决定；须与 L4 记忆管线协同设计，避免双写漂移。

### L3 · 子代理隔离与摘要回传
- **来源**：G 类；对标差距维度 1/8；多 Agent 编排的地基。
- **现状**：无隔离式子代理；「账本 + 裁判」runtime 天然支持 orchestrator-worker
  扩展（编剧/分镜/音频子 agent）。
- **目标态**：子代理独立上下文执行、只回传摘要；扩展时保持 ADR-0004
  主体性原则（模型唯一行动主体）。
- **触发条件/优先级**：出现单循环上下文装不下或需并行专业分工的真实需求时启动；中。
- **风险**：过早引入多 agent 会放大层间冲突；须先有 L1 双轨评测兜底。

### L4 · 记忆两阶段蒸馏 + 主动遗忘（含记忆分层演进）
- **状态（2026-08-23；2026-08-28 用户裁决补记）**：记忆系统已于批次 D **有意**
  退役删除（使用价值低），本项冻结、当前阶段不重建（用户显式裁决）；
  评审不得将 `data/memory/` 空置判为缺陷。重启条件：出现跨会话决策丢失的
  真实事故，且经用户裁决同意；若未来重新引入长期记忆，需从零重新论证。
- **来源**：G 类；对标差距维度 3（记忆）。
- **现状**：单层混合检索 + fallback 降级；无会话内提取/会话间蒸馏两段管线，
  无主动遗忘。
- **目标态**：会话内轻量提取 → 会话间蒸馏固化；usage-aware 检索 + diff-based
  forgetting 防记忆库腐化；远期演进为 core（用户偏好）/episodic（创作决定）/
  procedural（工序经验）三层。
- **触发条件/优先级**：记忆条目规模导致检索噪声可感时启动；中。
- **风险**：遗忘误删用户偏好；入库安全清洗（秘密扫描）必须先于遗忘机制。
