# 对画布（infinite-canvas）项目的需求清单与集成边界声明

> 来源：2026-08 集成审查（详见《修复改进计划书-2026-08.md》P0-4）
> 背景：本项目（自己做agent）通过 iframe（hash 引导 `#agentUrl`/`#agentToken`）+ canvas-agent HTTP 协议（`/api/tools`）集成画布。
> 受 ARCHITECTURE_RULES.md Rule 7 约束，本项目不修改画布代码；以下能力只能由画布侧实现。
> 集成已全面改经 canvas-agent 协议（原直连画布 HTTP API 与 postMessage 选中态方案已退役）；如未来确需 postMessage 类新能力，在重新引入 postMessage 桥接层前须先与画布侧对齐。

## 需求 1：`canvas:ready` 握手消息

**场景**：画布 iframe 加载完成后，主动向父窗口广播就绪信号。

**建议实现方向**：画布页初始化完成后经 canvas-agent 或 postMessage 广播就绪信号（旧 postMessage 样例仅存档）：
```js
window.parent.postMessage({ type: 'canvas:ready' }, '*');
```

**价值**：本项目可精确感知画布就绪/重载时机，用于清除过期选中缓存、触发状态同步，替代目前的健康探测轮询。

## 需求 2：选中态感知 —— 已解决（集成边界声明）

**原痛点**：画布内选中态只存在于画布浏览器端内存，服务端不持久化、无 API，Agent 的 @ 提及无法感知画布内选中。
**现状**：已由 canvas-agent 工具闭集解决 —— 读选中态走 `canvas_get_selection`（后端端点 `GET /api/canvas/selection`），反向选中走 `select_nodes`（后端端点 `POST /api/canvas/select-nodes`）。无需画布侧再做 postMessage 广播。
**边界约束**：选中态依赖画布编辑器客户端与 canvas-agent 的 WS 连接；客户端未连接时接口返回离线态，前端已带宽限重探。

## 需求 2 残留场景：画布内选中变化实时推送（可选）

canvas-agent 的 `canvas_get_selection` 是拉取式；若未来需要选中变化的**实时推送**（免轮询），需画布侧通过 canvas-agent 增加事件推送能力。

## 需求 3：反向选中联动 —— 已解决（集成边界声明）

**原场景**：用户在画布中点击某节点时，向父窗口广播节点 id。
**现状**：Agent 侧主动选中画布节点已由 `select_nodes` 解决；“画布点击 → 故事板草稿卡片联动”方向的实时事件推送仍依赖画布侧能力，列为可选需求。

## 需求 4（可选）：`canvas:node-update` 节点数据变更广播

**场景**：画布节点内容（如图片替换、文案修改）变化时广播 `{ type: 'canvas:node-update', nodeId, data }`。
**价值**：保持故事板与画布内容一致，减少手动刷新。

## 需求 5（可选）：放开或收窄跨源消息校验

**现状**：画布画布页 message 监听对跨源消息直接丢弃（`event.origin !== location.origin` 时 return），导致本项目发送的 `studio:draft-select` / `studio:state-sync` 无效。
**建议**：若画布希望支持被嵌入集成，可改为白名单校验（允许配置的父窗口源），而非仅同源。本项目的主题同步（`studio-theme`）之所以生效，正是因为 `theme.js` 未做 origin 校验。

## 裁决记录：运行时“工具能力清单对照探测”降级为契约测试守护（集成边界声明）

**背景**：修复改进计划书三道闸第 2 条（细分项）原要求运行时对照探测画布 34 工具闭集与本项目依赖面。
**裁决（2026-08-28 迁移终审）**：不在运行时逐次探测工具能力清单，改由契约测试（`tests/integration/test_infinite_canvas_contract.py`）+ canvas-agent 版本漂移告警（`check_version_drift`，钉住 `PROTOCOL_VERSION`）静态守护；启动期版本漂移命中时重跑契约测试确认兼容。
**理由**：工具闭集由对端 schemas.ts 单轨声明，运行时探测重复契约测试职责且增加探活开销；漂移风险已由协议版本钉住值 + 契约测试拦截。

---

**附：本项目已生效的集成面**（无需改动）：canvas-agent HTTP 协议（`/api/tools` 工具调用、`/health`）、hash 引导（`#agentUrl`/`#agentToken`）、`studio-theme` 主题消息；后端对前端暴露 `/api/canvas/*`（list/selection/select-nodes/drop-image 等）。
