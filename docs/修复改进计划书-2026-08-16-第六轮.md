### S2 契约门禁咬合化（N1③，D1 终裁：路线 a 前端全量迁移）

**背景**：生成物当前零消费，门禁只保「生成物↔schema」一致，前端手写类型与后端的
真实漂移抓不到。**用户终裁路线 a**：前端 API 边界类型全量迁移到生成物。

**执行方案**：
1. **盘点**：全量 grep 前端 fetch/请求体构造点与 `types/index.ts` 中属 API 边界的
   手写接口（AgentChatRequest 等）；视图态类型（ChatMessage/草稿卡等纯 UI 形态）
   保留手写（不属于 OpenAPI schema 范畴）；
2. **迁移**：API 请求/响应类型改从 `@/types/api.generated` 导入；手写同名接口删除，
   `types/index.ts` 仅保留 re-export 别名（调用方命名空间不动，G4 最小改动面）；
   SSE done payload 等后端未建模为 Pydantic 的载荷：非流式端点已有 ChatResponse
   覆盖同构字段者按生成物迁移，纯 SSE 事件载荷留手写并在文件头注释登记豁免理由；
3. **漂移修齐**：迁移中 tsc 暴露的字段不一致即真实漂移——后端 schema 缺失而前端
   实际在用的字段，补后端 Pydantic 模型字段（重生成生成物）；前端用错名的改前端；
   逐处记录于本批 commit message；
4. **回归**：tsc --noEmit + vitest + eslint 全绿；`gen_api_types --check` exit 0；
   生成物自此有了真实消费方——契约漂移将由 tsc 编译期直接报错（比桥接测试更彻底，
   桥接测试方案随路线 a 作废，T21 观察项不再设立）。

验收：前端无 API 边界手写类型残留（豁免项有登记注释）；tsc/vitest 绿；故意改后端
schema 字段名可复现 `--check` 红 + tsc 红（自验证后还原）。

### S3 验收一键化（N3，五轮 M6 清偿）

1. 新增 `scripts/acceptance.py`：串行执行并收集 exit code——
   pytest / vitest / tsc / eslint / gen_api_types --check / check_prompt_budget /
   check_file_lines / check_func_imports；
   - 输出**纯 ASCII** PASS/FAIL 汇总表 + 各项耗时；任一 FAIL → 进程 exit 1；
   - 子进程环境注入 `LOG_FILE_ENABLED=false`（与 S4 联动，防验收过程本身触发日志争用）;
   - `--with-eval` 选项追加 run_eval_pipeline（默认不含，评测较慢；D2 裁决）；
   - `--quick` 选项跳过 pytest 全量只跑三门禁+契约（小批快验用）；
2. 宪法修订（S6 统一落文，此处定稿内容）：§5.5 与 §10 的「验收四件套 + 门禁」
   人肉清单改为「跑 `python scripts/acceptance.py`，全 PASS 才可提交」；
3. CI 不动（Job 拆分比单脚本信息量大，保留；本地与 CI 组件同构）。

验收：acceptance.py 本机跑通全 PASS（含 S1 修复后的契约门禁）；故意制造一项失败
（临时改动）验证 exit 1 与 FAIL 定位后还原。

### S4 日志争用治理（N2，G4 覆盖三类进程）

1. **开关**：config.py 新增 `log_file_enabled`（env `LOG_FILE_ENABLED`，默认 true）；
   app.py 文件 sink 仅当开关为真时添加（stdout sink 不动）；
2. **测试进程隔离**：tests/conftest.py 顶层 `os.environ.setdefault("LOG_FILE_ENABLED", "false")`
   （pytest 全程不写生产日志文件——测试日志走 stdout 捕获即可）；
3. **脚本进程隔离**：acceptance.py 子进程环境注入同键（S3 已含）；门禁脚本单独手跑
   时若仍有争用，属可接受残余（非验收路径），不追加机制；
4. **服务进程唯一化**：`启动服务.bat` 在拉起 Agent 服务前增加杀旧进程步骤
   （§5.4 机制化）：`for /f` 解析 `netstat -ano | findstr :8080` 的 LISTENING PID，
   存在则 `taskkill /PID /F` 后提示；画布 3000 端口同逻辑处理；
5. **回归**：单测断言 env 关闭时 app 模块加载后无文件 sink（loguru 内省）；
   bat 行为由用户手动目测一次（启动两遍验证旧进程被替换）。

验收：pytest 输出无 PermissionError 日志块；服务与测试并行跑不再争用。

## 五、决策点（已审定 2026-08-16）

| # | 决策点 | 终裁 | 裁决理由 |

| D1 | 契约咬合路线 | **路线 a：前端全量迁移到生成类型**（用户裁决） | 彻底咬合：生成物成为真实消费方，漂移由 tsc 编译期直接报错；桥接测试方案作废，T21 不再设立 |
