### 本轮新发现的遗漏与修复

   签名没有该参数 → 执行器一调真实供应商就会 TypeError。已补上参数并透传给
   `_apply_thinking_level(payload, level)`；`base_chat.py` 抽象契约同步补回（预损伤终版有）。
2. **记忆模块回退丢失**：`memory/manager.py / models.py / vector_store.py` 恢复预损伤终版
   （`build_context_with_hits`、写入去重、`list_records/pin_record/delete_record`、`pinned` 字段），
   `tests/unit/test_memory.py` 同步恢复（+4 用例）。这同时补上对话栏「记忆参考」折叠区的数据源。
3. **memory_hits 下发链路**：`PlannerContext/PlannerResponse` 增加 `memory_hits`，
   `prompt_builder` 已有预损伤接线（`build_context_with_hits` → `context.memory_hits`），
   done payload 与非流式返回均带上；前端 `SseDonePayload` 补 `memory_hits`、
   `stores/chat.ts finishStream` 映射到 `ChatMessage.memoryHits`。
4. **SSE 事件常量**：`SSE_DOC_WRITTEN / SSE_MODEL_FALLBACK / SSE_GUIDANCE_INJECTED`
   恢复进 `sse_events.py`（预损伤契约）；流式路径透传 `guidance_injected`，
   fallback 切换时下发 `model_fallback` 事件；前端 `use-sse.ts` 补对应处理
   （`applyFallbackModel` + 引导气泡/排队区移除），`stores/agent-prefs.ts` 恢复
   `applyFallbackModel`，`api/agent.ts` 恢复 `sendGuidance`。
5. **memory 路由未接线**：`app.py` 补挂 `/api/memory` 路由（保留 runtime_settings 路由），
   并恢复 `/health` 健康检查端点。
