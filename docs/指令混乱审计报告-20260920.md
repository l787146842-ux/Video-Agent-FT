## 一、flova 权威依据（用户亲询原话，非推测）

用户在 `06 flova/flova 10.md` L914 问 flova 的正是 Q1/Q3 同源问题。flova 回答（L900-989）给出三条硬原则 + 一条关键细分：

1. **剧本正文不因上传自动进主会话**（L901）：「主会话能看到剧本文档的存在、路径和资源标识……但剧本文字正文不会因为上传就自动注入到主会话上下文；只有当我主动打开、或把它作为依赖交给素材分析阶段时，正文才进入那个环节。」→ 即「**能读而又不读**」（L903-905）：读能力保留，默认不把正文塞进主会话。
2. **分工**（L983-985）：素材分析阶段负责「读剧本 + 发现缺口」；Planner 负责「拿到缺口后向用户追问 + 决定是否推进」。
3. **依赖顺序**（L971）：`主会话先确认启动必答项（输出语言）→ 素材分析读剧本识别缺口 → Planner 就「已识别的具体缺口」精准追问 → 确认后才进制作设定与分镜`。
4. **关键细分（L987，上一版漏掉、本轮补回）**：「Planner 在启动时**也可以**先问已经明确缺失、且**不依赖剧本判断**的全局参数（画幅/目标时长/输出语言/整体影像方向）；只是『哪些角色、哪些场景缺什么细节』**必须先读剧本**才能准确列出，此时先分析后追问才是合理依赖顺序。」

**flova 的红线只有一条**：*依赖剧本内容的细节*（哪个角色/场景缺什么）不能在分析前问；*不依赖剧本的全局参数*（画幅/时长/风格/语言）启动时问**是可以的**。flova 主代理**从不亲自读剧本正文**——这条是结构性的（正文不进主会话），不是靠「剥夺读工具」。
