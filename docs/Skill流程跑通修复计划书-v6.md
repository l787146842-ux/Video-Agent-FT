## 三、总体思路（一句话）

**闸机继续拦（宪法 §2.7 不动），但把"什么算用户同意"补完整：**
撞闸 → 指引回喂给模型（循环不终止）→ 模型发暂停卡展示提示词草案 → 用户接受 = 登记一次性生成同意 → 模型重提放行。
偏好档位同时注入模型上下文，让 confirm_before_gen 档下模型**主动**先审后生成，少撞闸。

## 附：一句话总结
