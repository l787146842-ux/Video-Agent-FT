# ADR-0007：Skill = 指令性制作手册（对齐 Flova / Claude Code / Agent Skills 开放标准）

- 状态：已接受（2026-08-29，用户显式裁决，不可再议）
- 不取代任何既有 ADR：「Skill 全文是数据，不是指令」原为宪法 §2.2 条款与
  GOVERNANCE G1 的表述源，从未由 ADR 设立；本裁决随宪法 v8 同批改写该两处
  表述源（双边口径同步，见后果节）。
- 触发：skill 系统全面对齐业界（Flova / Claude Code / Agent Skills 开放标准）；
  用户裁决「宪法必须改、G1 必须推翻」——Skill 从「数据」重新定位为
  **指令性制作手册**。

## 用户裁决全文（2026-08-29）

1. Skill = **指令性制作手册**：教 Agent 理解任务 / 拆步骤 / 调工具 / 选模型 /
   出片，创作者自由书写；加载走开关 + Agent 判断 + 渐进式披露。
2. 全面对齐业界：Flova / Claude Code / Agent Skills 开放标准；支持携带引用
   素材并锁版本。
3. G1 推翻：废除 Skill 只读属性，走 GOVERNANCE §13.12 G1 自带的「用户显式
   裁决例外」通道留痕（见 ADR 与 §13.12 双边注记）。
4. 四条红线保留（业界同样如此）——
   - §2.4 Context ≠ Consent：Skill 正文不构成用户同意；
   - Platform 层闸机绝对不可被 Skill manifest 关闭
     （gate_registry LAYER_PLATFORM）；
   - 确认闸（§2.7：花钱/高危操作必须用户点头，Flova 只会更严）；
   - 动作单轨 FC + guard_pipeline 唯一判定；scripts 键只静态校验绝不执行
     （Flova skill 本就无脚本，零差异）。

## 总原则（每批自查）

系统与 Skill 冲突时，修系统，不改 Skill 迁就系统；每一条涉及 Skill 的改动
都必须能回答「业界（Flova / Claude Code / Agent Skills 标准）也是这么干的吗」，
答不上来的私货一律砍掉。

## 业界对标

| 基准 | 事实 |
|---|---|
| Flova | skill 是指令性制作手册，创作者自由书写；卡片开关启停；目录摘要常驻 + 正文按需加载以节省上下文；支持携带素材资源并锁版本 |
| Claude Code | skill 正文是指令（instructional），经渐进披露注入；不给 skill 内容贴约束性包壳 |
| Agent Skills 开放标准 | 单一包形态 `<slug>/SKILL.md`，frontmatter `name`/`description` 必填 |
| 共识 | **skill 是指令性制作手册；单一标准包形态；渐进披露注入；官方内容干净注入，安全兜底靠机械装置不靠文本贴符** |

## 决策

1. **定位**：Skill 是指令性制作手册，指令仅在创作流程内有效；不能覆盖平台
   闸机、不构成用户同意（宪法 §2.4）、不能要求执行平台外动作。宪法 §2.2
   原「不可信前提」与「触碰 `platform.*` 静默忽略 + warning + 负面测试」条款
   原样保留。
2. **形态**：单一包形态 `<slug>/SKILL.md`（对齐 Agent Skills 标准，
   frontmatter `name`/`description` 必填）。官方/平台 Skill 干净注入
   不加任何包壳；仅外部导入 Skill 带来源标记。
3. **加载**：三级渐进披露——开关 → 目录摘要常驻 → 正文预算化注入 /
   资源按需（read_skill 续读）。
4. **G1 重写**：GOVERNANCE §13.12 G1 废除只读属性，改为「Skill 改动裁决关」；
   保留「禁止以降低 Skill 要求的方式迁就系统缺陷、优先修平台层」内核；
   本裁决即走该节自带例外通道留痕。
5. **红线不动**：裁决全文第 4 条四红线全程保留，业界同样如此。

## 落地批次（计划书：Skill 系统对齐 Flova 重构）

批 1 修宪与治理文书（含 P0-2 坏指针，零代码）→ 批 2 确认闸数据驱动化 +
文案外置 → 批 3 SKILL.md 单一形态 → 批 4 指令性注入合法化 + 注入面规整
→ 批 5 开关 + 目录预算 → 批 6 素材资源与版本锁 → 批 7 前端开关（用户目测）。
清偿要件逐批登记于 `docs/未清偿债务清单.md`（D-07），清偿一批删一行。
