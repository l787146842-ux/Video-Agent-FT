# ADR-0004：主体回归——模型永远唯一行动主体（宪法 Rule2 修订）

- 状态：已接受（2026-08-21，用户审定裁决；审核整改批 4）
- 取代注记：ADR-0003 的「runtime 机械直跑 / 审批直跑」决策退役；其
  阶段表/依赖图/客观探针/闸内嵌执行路径/原子轮提交/四投影同源保留为
  账本与裁判数据层职能。
- 部分取代注记：条款 4 的互斥拒收语义由 ADR-0006（阻塞化暂停）取代；
  「暂停卡唯一发行主体 = 模型 workflow_pause」与系统派生选项面/层 9 兜底引导卡保留。
- 触发：2026-08-21 全面审核用户质疑——「一切流程都要根据 Skill；直跑是
  用户要求不暂停、按 Skill 流程一直跑（模型工作），不是系统内部机械执行；
  一开始就自动分析剧本，要模型干嘛」。追溯发现 0818→0820 三轮整改中
  「直跑」语义渐变为 runtime 代替模型行动，与原设计意图漂移。

## 业界核实（2026-08-21 联网检索）

| 基准 | 事实 |
|---|---|
| Codex CLI | `--full-auto` 是**审批档**：模型连续干活不逐条确认；模型始终在环 |
| Claude Code | auto mode / acceptEdits：权限闸自动放行**模型的决定**；钩子从不代替模型行动 |
| DeepSeek Harness | 循环 = 上下文交模型→模型返回工具调用→执行→回喂；审批是 waterfall 插件，挂在工具执行前 |
| Anthropic workflow | 代码可持有编排顺序，但链上每个节点仍是 LLM 调用；代码排序不做语义创作 |
| 共识 | **确定性 = 把关模型发起的动作（hooks/gates/sandbox），不是系统代替模型发起动作；「不暂停」是用户授予模型的权限档** |

ADR-0003 以「hooks guarantee behavior」为机械直跑背书属引用方向错误：
该公理的含义是钩子保证**模型行为**的边界，不是代替模型行动。

## 决策

1. **模型永远唯一行动主体**：每轮做什么由模型接到用户消息后发起工具调用；
   `workflow_runtime` 降级为「账本 + 裁判数据层」（定义编译 / run reducer /
   产物账本 / 投影 / 客观探针），不发起任何行动。带附件首条消息由模型接手
   （读后调 script_analyze），系统不静默自动分析。
2. **顺序保障 = 刹车不是方向盘**：阶段表/依赖图/stage_precondition 闸全保留，
   全部体现为工具执行路径首位否决（模型越阶即结构化拒收回喂）。
3. **「不暂停连跑」恢复为自主性档位**（批 5 落地）：用户指令或开关授予模型
   豁免非平台硬暂停点；平台硬闸（生成/写文档/跨阶段建结构）任何档位必停
   （Context ≠ Consent，授权留痕）。批 B 补充：提醒场景豁免按确认类别泛化
   （stage_probes.CONFIRMATION_WAIVER_FLAGS，经 reduce_interaction 写入）——
   同类确认批过一次不再问，属用户显式确认授予的豁免留痕。
4. **暂停卡唯一发行主体 = 模型 workflow_pause**（对齐 AskUserQuestion）；
   单一活跃暂停槽位互斥：`interaction.active_pause` 未消费时重复暂停拒收并
   结构化回喂留痕。系统派生选项面、层 9 兜底引导卡（原料闸/规格闸提醒）保留。
   （互斥拒收语义已被 ADR-0006 取代：问即停后重复暂停降级为防御断言，
   新卡覆盖旧卡只告警留痕；发行主体与槽位唯一性不变。批 B 后提醒类
   兜底卡出槽：不登记 active_pause，改走正文注入 + quick-actions 芯片。）
5. **性能解法 = 不让模型猜**：客观状态 + Skill 声明下一步 + 系统建议直达
   上下文，阶段过渡目标 1 轮 1 次工具调用；而非不让模型参与。
6. **退役符号防复活**：runtime 直跑驱动符号登记 check_legacy_orchestration。

## 后果与验收

- 测试按新语义重写：test_workflow_runtime_1111 / test_orchestrator_golden /
  test_workflow_runtime_wiring / test_workflow_runtime_batch4（退役守卫）；
  新增暂停槽位互斥用例（test_pause_structure::TestPauseSlotMutex）。
- 代价（用户已知悉并接受）：阶段过渡各花一轮模型调用（性能换主体性）；
  顺序漂移由「不会发生」变为「发生必被闸拦截纠偏」。
- collect_spec 候选出题保留为客观数据预取（轮始幂等点火，非行动发起）。
- 治理：控制流范式表述唯一归宪法 Rule2（P1），本 ADR 与 ADR-0003 仅指针。
