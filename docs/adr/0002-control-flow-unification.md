# ADR-0002：控制流统一（废除概率路由，单一外层循环）

- 状态：已接受并执行（2026-08-19，audit-0819e，用户审定计划书）
- 触发事故：1111 项目——编排器整轮缺席，模型越过规格阶段直拆故事板，
  规格向导卡从未弹出、规格文档从未写入
- 关联：宪法 Rule 2「控制流统一」条款、`docs/adr/0001-dual-track.md`、
  `core/scaffold_registry.py` S04 下账

## 背景（事故诊断）

0818「混合模式」把控制流分成两个入口：编排器快路径与模型循环，由
`_route_orchestrator` 按**概率语料**（`_ADVANCE_CORPUS` 推进词表等）决定
每条消息走哪边。1111 项目证明这个接缝是结构性缺陷：

1. 路由错过一次 = 全程失控（模型循环内无任何阶段监督）；
2. 工具裁剪名单漏了三个拆解执行器（越阶的真正入口）；
3. spec_gate 只软警告，无「规格前置」硬闸；
4. 路由决策与编排器进出**零日志**——事后只能考古。

## 业界依据（正向设计，非补丁）

| 原则 | 依据 |
|---|---|
| Hooks guarantee behavior; prompts suggest——确定性强制必须内嵌工具执行路径 | Claude Code PreToolUse hooks |
| 旁路钩子会静默失败/被绕过，强制必须是执行路径的必经环节 | Anthropic RFC#45427 |
| 单一 agent 循环；确定性活在沙箱/审批层，不做概率路由 | Codex agent loop + approval policy |
| 控制流是一等公民（循环本身可插拔、审批是结构化事件） | DeepSeek Harness「一切皆插件」 |
| Agent = 单一就绪单元调度器：任一时刻至多一个控制实体活跃 | arXiv 调度理论框架 |

## 决策

1. **阶段前置闸（平台不变量）**：`platform.stage_precondition` 进 GATE_RULES
   （platform 层，manifest 无权关闭），接在 fc_tool_runner 闸机链**首位**：
   工具归属阶段（阶段表 executors 声明 + 平台映射表，单一事实源）的前置
   阶段未完成 → 拒收 + 结构化拒因回喂；用户坚持（gate_override）可一次性
   豁免并留痕。未声明依赖回落线性前置，且比调度更保守（无前置的阶段补
   线性前置，`_effective_stage_deps`）。
2. **控制流统一（废概率路由）**：一切消息先过确定性分诊
   `_triage_control`（advance/handoff），只认客观状态事实（待确认暂停、
   一条龙豁免、系统按钮机械文案、原料就位、管线启动状态），零措辞猜测；
   `_ADVANCE_CORPUS`/`_ADHOC_VERBS` 删除（S04 下账，基线随降）。
3. **步间回收（between_steps）**：`run_agent_loop` 新增回收钩子，每个 FC 批
   落盘后外层循环再评估（orchestrate_turn）——确定性阶段就绪/应发机械卡
   即回收控制权终止循环；stage_failed 保守化不劫持；钩子异常 fail-open。
   语义 = 单一就绪单元：模型循环只是随时可被回收的执行单元。
4. **可观测性**：分诊/阶段批/交接/回收全记 `tracer.record_control_flow`
   （滚动事件流，`control_flow_events()` 可查）+ `[ControlFlow]` 日志。
5. **裁剪补洞**：三个拆解执行器 + write_media_prompt 补进
   STORYBOARD_STAGE_TOOLS（可见性软层与前置硬闸双层一致）。

## 与 0818 裁决的关系（诚实载明）

0818 用户裁决 = 混合模式（编排器主路径 + 模型循环回落）。本 ADR 是其
**正向设计升级而非推翻**：混合语义保留（确定性阶段编排接管 + 创作型阶段
模型交接），接缝从概率路由换为确定性分诊 + 步间回收——「两个大脑抢方向盘」
变成「一个方向盘，模型是被调度的执行单元」。

## 后果

- 越阶在三层都不可能：分诊（入口确定性）→ 步间回收（循环中监督）→
  阶段前置闸（执行路径内嵌硬强制，兜底中的兜底）；
- 首轮行为变化：带原料的首条消息直接由编排器开局（机械跑分析/回原料卡），
  不再经模型 read_skill——这正是修复目标；
- 回收钩子在模型循环每个 FC 批后评估一次编排器（纯状态计算，无 LLM 开销；
  仅当确定性阶段就绪才执行执行器）。
