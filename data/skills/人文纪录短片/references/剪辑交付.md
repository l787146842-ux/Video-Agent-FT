# 剪辑交付

## 节奏原则

- 长镜头优先，保留完整的时间流动感；不为追求「有趣」而剪短镜头。
- 镜头之间可用半秒到一秒的黑场或声音延续过渡，制造呼吸感。
- 禁止快剪、音乐卡点、特效转场与短视频式节奏。
- 相邻镜头如果跳轴，优先靠换一个观察角度解决，而不是插入表演式过渡镜。

## 音画关系

- BGM（如有）音量低于视频层声音，淡入淡出，不抢画面。
- 不做强制音画同步；画面与声音各自自然流动，现场环境声承担主要氛围。
- 环境声（市集、风、雨、街道）与画面空气中的介质要对应：画面有风就该有风声，画面潮湿就该有湿润的底噪。
- 旁白若存在，音量与画面环境声分层清楚，不与市集噪声糊在一起。

## 常见失败与修复

| 现象 | 原因 | 修复方向 |
| --- | --- | --- |
| 成片像城市宣传片 | 分镜把景观当主体 | 回改分镜，先拍人不拍城 |
| 画面有 AI 感或商业感 | 首帧图或提示词混入非纪实描述 | 重写提示词重出首帧与该镜 |
| 出现炫技运镜或快切 | 运镜越界 | 回退为固定、微弱手持或极慢推拉，重生成 |
| 镜头信息量太低 | 分镜时长达长但动作是空的 | 补微小动作与空气感细节，或剪短 |
| 情绪靠配乐硬推 | BGM 抢画面 | 压低 BGM，改用现场环境声承担氛围 |
| 画面里出现文字或字幕 | 负向约束缺失 | 补禁止项后重生成 |
| 光学完美但不像纪录片 | 缺少失焦、曝光波动等真实瑕疵 | 允许并保留轻微不完美，重出该镜 |

## 导出基准

- 画幅、分辨率与帧率继承全局预设；片名与总时长遵循制片规格。
- 导出前完整过一遍：是否从人切入而非从景切入、每个镜头是否有空气感与自然光、运镜是否全部在允许清单内、BGM 是否压过现场声、片中有无文字与字幕残留。
- 交付时说明所选地域与视觉风格定位，便于用户核对是否偏离纪实口径。
