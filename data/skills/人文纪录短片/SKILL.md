# 人文纪录短片

## 一、目标、输入与交付

本 Skill 做人文观察式纪录短片——用国际纪录片与自然地理式的观察影像语言，拍「真实的人」与「普通人的生活」。它明确不是城市宣传片：宏大景观与城市面貌永远不是首要表现对象，剧情永远从人切入，靠普通人的真实生活状态折射其背后的文化与环境。

输入包括：题材与地域（在亚洲、非洲、中东、南美、东欧、东南亚、海岛国家、发展中国家等范围内选定）、片名方向、画幅与目标时长、参考图片或视频、输出语言。用户提供的参考素材只做结构化信号提取，不做主观评价。

交付是按故事板顺序组装、音画自然流动的成片。生成渠道、模型、分辨率、时长一律以全局设置为唯一权威，本文档不写死这些参数。

## 二、项目结构规划

- 「关键元素」优先设计人物元素（年龄、外貌、着装、正在做的事）与场景元素（地理环境、时段、光线条件、空气质感）；道具元素只在对多个镜头一致性有实质影响时才单独建立。
- 有序序列按观察顺序组织镜头，每个镜头是序列下一个分组；每个镜头挂一张首帧图作为视频生成的视觉锚点。
- 「音频」分组管理 audio_layer：BGM 可选且限定为极简器乐或环境音景；不设以对白驱动叙事的条目。
- 剪辑按故事板顺序组装时间线。

## 三、制片规格

把全局制作参数写入 制片规格.md（走 document_write）：片名、题材地域、画幅比例、目标时长、视觉风格、输出语言。四项要写死：

- **片名**：契合人文纪录调性，避免过度商业或浮夸的命名。
- **题材地域**：在给定的区域范围里选定；题材核心必须聚焦真实的人与普通人的生活，拒绝城市宣传片逻辑。
- **视觉风格**：锁定为「像真实摄影师长期驻扎拍摄」「像国际电影节纪录片」「流媒体平台纪录片风格」或「自然地理式观察影像」之一，并写明避雷清单——严禁 AI 感、商业广告感、强戏剧感、网红风。
- **画面质感**：必须有空气感（灰尘、水汽、潮湿、热浪、风）；光线仅限自然光（晨光、黄昏、阴天、窗边光）；允许并刻意保留轻微失焦、曝光波动与真实混乱感。

画幅以横屏为主，也可用宽银幕，具体按全局设置确认。

## 四、创作流程规划

**启动协议**：先确认片名方向、题材地域、画幅与目标时长、视觉风格选项，四项确认后才写规格；用户只给一句「拍一个纪录片」时，按上述四个维度引导其做出选择，而不是自行拍板。

1. 与用户确认并建立 制片规格.md。
2. 生成故事板：关键元素、镜头列表、音频层；故事板就绪后扫描当前上下文，找出用户提供或此前生成的、与故事板条目匹配的任何资产，在生成前先绑定并分配到对应槽位。
3. 设置元素：用户已上传的元素资源直接绑定；其余生成图像。
4. 为每个镜头生成首帧图，规则见 `references/媒体生成.md`。
5. 参考首帧图生成视频。
6. 生成 BGM 音频层。
7. 完成全片时间线组装，规则见 `references/剪辑交付.md`。

**依赖关系：** 2→1；3→2；4→2；5→4；6→2；7→5,6

**何时暂停：** 不得一次性跑完全部流程。故事板完成、元素图与首帧图完成、视频完成、音频生成完成后各暂停，等用户确认再继续。暂停走 workflow_pause，不得声称用户已经同意。

**用户已有媒体优先：** 用户提供或预先存在的媒体，先在生成前绑定并分配到适当的故事板位置，避免重复生成已有内容。

## 五、专业创作方法

**核心叙事理念：观察生活，而不是拍故事。**

- **去戏剧化**：摒弃强戏剧冲突与商业广告式剧情设计。重点不是讲一个起承转合的故事，而是呈现真实世界的人类生活。
- **偶发感**：场景与事件不能有「导演刻意安排」的痕迹，必须营造出「摄影师长期驻扎时偶然观察到」的自然状态。
- **全球纪录片统一审美**：追求国际流媒体与自然地理式的观察影像质感，让全球观众都能理解与共情，避免刻板的单一地域风（纯网红风、纯欧美风）。

**叙事主体：先拍人，不拍城。** 永远不要把城市面貌或宏大景观作为剧本的首要表现对象。剧情从人切入。

**最易共情的描写点（写在分镜里，而不是写宏大事件）：**

- **手部劳作**：做饭、缝纫、洗衣、写字、手工劳动。
- **背影与状态**：多使用背影作为主视觉，比直接展现正脸更有留白与高级感。
- **日常微小动作**：点烟、喝茶、发呆、看着窗外，用这些没有特定目的的小动作构建时间流动的真实感。

**地域题材库（按所选地域直接取用最能体现当地原生人文气息的场景）：**

| 地域 | 典型场景与事件 |
| --- | --- |
| 亚洲 | 清晨的早餐摊、老茶馆里的闲谈、熙攘的传统市场、原生态渔村、老旧铁路边 |
| 非洲 | 黄昏尘土下的归途、热闹的集市、奔跑的孩子、雨季的日常、传统手工劳动 |
| 南美 | 随性的街头音乐表演、充满生活气息的老城区、海边日常、土路足球场、夜市烟火气 |
| 中东 | 阳光穿透的传统市场、专注的手工艺制作、虔诚的祈祷时刻、沙尘环境下的生活常态 |

**分镜设计原则：**

- **时长**：镜头时长按全局设置，避免设计过短、缺乏信息量的镜头。
- **观察性叙事**：镜头不「设计故事」，而是「偶然看见生活」；优先手部劳动、背影、微小日常动作，避免正面表演式构图。
- **运镜极简（按优先级）**：一个分镜只描述一个镜头，依次优先固定镜头、微弱手持（仅呼吸感或轻微漂移）、极慢推进或极慢横移；禁止旋转、快速推拉、无人机飞行、炫技运镜、切镜。
- **每个镜头描述必须包含**：场景引用（场景元素 ID，说明时段与光线）、主体动作（正在做的微小动作，以肢体和神态为主，无需台词）、摄影语言（景别加运镜类型加焦点策略）。

**画面质感三条硬要求：**

- **自然光优先**：晨光、黄昏、阴天散射光、窗边侧光；禁止人工补光感。
- **空气感必须体现**：灰尘、水汽、热浪、潮湿、轻雾中至少选一种写进镜头描述。
- **允许不完美**：轻微失焦、曝光轻微波动、人物短暂停顿都是真实感的加分项，不是缺陷。

**色调体系：** 低饱和、高层次——高光柔和不过曝，暗部有细节不死黑，肤色真实。参考方向是经典胶片与自然色彩的科学调色。

**声音设计：** 市集噪声、风声、雨声、街道声这类现场环境声是叙事的一部分。BGM 可选，若使用只选极简器乐或无调性环境音景，禁止流行音乐节奏。不以对白驱动叙事。
