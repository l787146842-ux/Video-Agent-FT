# 古风甜宠短剧

## 一、目标、输入与交付

本 Skill 把用户自带的剧本或自动生成的剧本，做成古装甜宠短剧成片。链路为：剧本来源确认 → 剧本审核 → 形象与背景设定 → 制作偏好确认 → 故事板 → 场景图 → 逐镜视频与音频 → 剪辑导出。每个里程碑结束都要暂停取得确认，下一阶段只在确认后推进。

输入包括：剧本（用户粘贴或描述，或授权本 Skill 生成）、男女主形象参考图、故事背景偏好、画幅与是否加 BGM 字幕的偏好。用户在项目启动时上传的男女主参考图是角色外观的最高权威，优先级高于剧本描述与任何其他上下文。

交付是按故事板顺序组装、音画同步的甜宠短剧成片。生成渠道、模型、分辨率、时长一律以全局设置为唯一权威，本文档不写死这些参数；本 Skill 的责任在剪辑导出引导完成时结束。

## 二、项目结构规划

- 「关键元素」里必须有男主、女主两个角色元素与至少一个核心场景元素。角色挂白底横向三视图，场景挂写实电影感场景参考图。
- 有序序列按剧情组织镜头，每个镜头是序列下一个分组，对应一次视频生成任务，优先在单镜内做内部剪切与情绪起伏。
- 「音频」分组管理 audio_layer：古风甜宠 BGM 至少一条，剧本有旁白或独白时另设 narration 轨并注明声线风格与覆盖镜头。
- 剪辑按故事板顺序组装时间线。

男女主形象图、场景图都要经过 storyboard_patch_draft 登记到对应元素的参考字段，作为后续视频生成的参考输入。

## 三、制片规格

把全局制作参数写入 制片规格.md（走 document_write）：画幅比例、目标时长、影像风格基调、输出语言、是否添加 BGM 与字幕。甜宠剧的画风基线是写实电影感——真实建筑与自然材质纹理、电影级自然光源、影调克制厚重，动画感与游戏 CG 感一律排除。

## 四、创作流程规划

**启动协议**：第一件事是确认剧本来源，再往下走。

**阶段 0：剧本来源确认。** 问用户是自己提供剧本还是由本 Skill 自动生成。自提剧本则请用户粘贴或描述后进入审核；选择自动生成则按甜宠爆款风格生成一份（目标时长按全局设置、镜头数对应到二十多个镜头、古装甜宠聚焦男女主情感互动、有起伏且每场戏有明确情绪落点、以场景加台词加动作描述呈现），生成后暂停让用户审核。

**阶段 1：剧本审核。** 把剧本呈现给用户邀请审核，确认后进入下一阶段；有修改意见就改完再确认。

**阶段 2：形象与背景设定。** 收集男主形象（外貌、服装、气质）、女主形象、故事背景（朝代氛围、主要场景风格如宫廷江湖山野书院）。用户无明确要求时按剧本角色给推荐描述。为男女主各生成一张角色参考图，生成完暂停审核，并明确问：对当前形象是否满意、能否继续生成场景，还是先调整人物。要调整就按意见重生成再确认。

**阶段 3：制作偏好确认。** 一次性问三项：画幅（默认按全局设置）、是否加背景音乐（默认古风暧昧轻音乐，可另行描述偏好或不加）、是否加字幕（加则后期合成时叠加，不加则在提示词里写无字幕反向约束）。

**阶段 4：故事板生成。** 依据确认过的剧本、形象描述、背景与画幅生成完整故事板（关键元素、分镜列表、独立音频轨），生成后暂停让用户确认。

**阶段 5：场景图生成与审核。** 为所有场景元素逐一生成场景参考图，写实电影感风格且与角色图规格一致；全部生成后暂停，逐张展示并问「当前场景图是否满意、可以进入视频制作，还是某个场景需要调整」。要改就重生成对应场景再确认。

**阶段 6：视频制作。** 把确认过的男女主形象图与场景图登记到故事板对应元素的参考字段；逐镜生成视频，每镜以对应角色图与场景图作参考，第二镜起把前一镜成片作为视频参考以保持站位与肢体动作连贯；生成 BGM 与旁白配音轨。

**阶段 7：剪辑导出。** 全部资产就绪后进入时间线合成与导出，由用户在工作台操作，本 Skill 引导。

**依赖关系：** 1→0；2→1；3→2；4→2,3；5→4；6→5；7→6

**何时暂停：** 每个里程碑结束必须暂停并取得确认，不得一口气推进全部阶段。重点节点：剧本生成后、剧本审核后、形象图生成后（必须明确问是否可以继续）、制作偏好确认后、故事板生成后、场景图生成后。暂停走 workflow_pause，不得声称用户已经同意。

## 五、专业创作方法

**爆款剧情三核心（缺一不可）：**

1. **极致人设反差**：男女主的表面形象与私下性格必须形成强烈对比（表面高冷内里撒娇、表面莽撞内里细腻）。设定时给男女主各设计至少一处令人意外的反差细节，并在剧本里安排对应的「人设暴露」场景。
2. **身份悬念钩子**：男女主都身怀秘密，「这个人到底是谁」作为贯穿全片的悬念线。每次靠近与试探都要让身份信息若隐若现，全片至少植入一处明确的悬念伏笔或反转暗示。
3. **高密度糖点铺排**：肢体接触（手触、对视、近距离）、语言撩拨、氛围心动必须高密度连续出现，不留冗余过渡，平均每个镜头至少一处甜点，每个甜点都要有明确的情绪爆发落点。

**形象设计基线（强制）：** 角色五官须符合短视频平台主流审美——五官精致立体、轮廓感强、颜值出挑，高鼻梁、双眼皮大眼、精致唇形、小脸尖下巴，整体兼具镜头感与话题感。同时必须真实写实：超逼真皮肤纹理、原生毛孔可见、面部细碎绒毛清晰，五官立体精致且有电影级人像光感。动画感与游戏感一律排除。男女主的固定形象描述见 `references/提示词写作.md`，默认逐字沿用，只有用户明确提出修改意见时才局部调整。

**参考图优先级（强制）：** 用户上传的男女主参考图优先级最高，高于剧本描述、场景氛围与任何其他上下文。剧本里的人物描述、身份设定、情节氛围都以参考图为准；面部特征、脸型、发型发饰、服装款式与配色全部由参考图锁定。用户主动更换参考图之前，任何生成都必须严格还原参考图外观。

**场景画风（强制）：** 所有场景用写实真实电影感风格——真实建筑与自然材质纹理、电影级自然光源（阳光透射、烛光、晨雾）、影调克制厚重；不能出现动画感、游戏 CG 感、概念插画感或过度后期感。画风不随剧本氛围变化而偏移。

**分镜设计：** 镜头总数与总时长按全局设置与确认的耗时目标设定，覆盖完整剧本。每个镜头偏向较长时长，优先在单镜内设计内部剪切与情绪起伏，而不是切成许多短镜。每个分镜必须写清场景引用、故事节拍（角色动作、情感状态、出自原剧本的逐字台词）、摄影语言（景别、机位角度、镜头运动）。甜宠情感节点镜头（对视、牵手、表白）重点设计特写加慢推，强化张力。

**节奏饱满（强制）：** 每个镜头的时长必须被动作或台词填满，不允许出现无实质内容的空镜或拖沓段落。每镜至少一个明确动作节拍或一句台词；纯氛围镜也要用人物微表情、肢体细节（衣袖轻动、手指收紧）或环境动态（风吹花落）填满叙事，「停滞等待」式的静默空场不在口径内。

**站位与动作锚点（每镜必做，无例外）：** 每个分镜的故事节拍开头必须用一句话写明本镜开始时各角色的站位、朝向与肢体动作起始状态，结尾必须用一句话写明本镜结束时各角色的站位、朝向与肢体动作终止状态。第二镜直接描述初始站位；第四镜起开头要引用上一镜末尾状态作为起点。这样故事板本身完整记录了全程站位流转，任意相邻两镜都能无缝拼接，后续写提示词可直接引用，不必回溯视频。

**情感戏的写法：** 对视、牵手、表白这类镜头重点写面部微表情、肢体接触细节与情绪节拍（由紧张缓慢松弛），用特写加慢推让观众看清情绪变化。

**音频设计：** BGM 至少一条贯穿全片，情绪转折明显时可拆成两段各自独立。默认方向是微微古风、轻度暧昧、轻柔流动的弦乐或琵琶笛音，情绪克制不外放。用户上传参考音频时只提取其整体风格氛围写进提示词，不直接拿该音频当输出。用户另有偏好时以用户描述为准。旁白或独白另设 narration 轨，注明声线与覆盖镜头。
