# 剪辑交付

## 剪辑节奏与过渡

- 严格按故事板镜头顺序组装时间线，不自行调换镜头次序。
- 情感高潮镜头（对视、表白）前后可设半秒到一秒的黑场或淡入淡出过渡，强化情绪停顿；其余镜头之间默认直切。
- 片头前几秒与片尾最后几秒做淡入淡出处理。
- 相邻镜头若跳轴，插入正面或过肩过渡镜；站位衔接以故事板里各镜的头尾锚点为准，不靠裁切去救。

## 音频混音层级

- BGM 音量低于人声与旁白，保证台词清晰；情感高潮段落可适当提升 BGM 音量。
- 台词与音效在视频轨内嵌，组装不重复叠加。
- 旁白轨与台词不得在同一时刻重叠，冲突时错开或调整覆盖范围。
- BGM 与人声交界处做交叉淡化，防止硬切造成音量跳变。

## 字幕处理

- 用户在偏好阶段选择加字幕时，在合成阶段为每个镜头的台词与旁白叠加对应字幕条目，时间点与人物说话节奏对齐。
- 选择不加字幕时跳过这一步，且视频提示词里已经写入无字幕约束，两处口径必须一致。

## 常见失败与修复

| 现象 | 原因 | 修复方向 |
| --- | --- | --- |
| 男女主长相偏离参考图 | 提示词自行改写固定形象描述 | 恢复固定描述与参考图绑定，重生成该镜 |
| 场景出现动画感或游戏感 | 场景图或视频提示词混入非写实描述 | 重做场景图或改写提示词后重生成 |
| 相邻镜人物站位突变 | 故事板缺头尾锚点或未绑定前镜 | 补锚点、补绑前一镜成片，重生成后一镜 |
| 镜头内容空、节奏拖沓 | 提示词无可执行动作或台词 | 按节奏饱满原则补微表情、肢体细节或环境动态 |
| 台词被 BGM 盖住 | 混音时未压背景乐 | 重新调整 BGM 与人声电平 |
| 字幕与台词不同步 | 字幕条目时间点未对齐说话节奏 | 按台词波形重排字幕时间 |
| 出现自带音乐或字幕 | 视频提示词未加反向约束 | 补写后重新生成该镜 |
| 甜点密度不足 | 分镜未按高密度糖点铺排 | 回改分镜，在关键节拍补糖点落点 |

## 导出基准

- 画幅、分辨率与帧率继承全局预设；导出前引导用户确认总时长是否落在确认过的目标区间，有偏差就通过调整镜头时长修正。
- 导出前完整过一遍：镜头顺序是否与故事板一致、情感高潮过渡是否到位、BGM 是否压过人声、字幕是否按偏好处理、片头片尾淡入淡出是否生效。
