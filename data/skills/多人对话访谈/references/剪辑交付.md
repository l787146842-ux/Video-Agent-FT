# 剪辑交付

## 对白优先的音频主控

- 把音频层当作旁白与对话的主控：在时间轴上静音每个生成视频片段里嵌入的音频，避免语音重复或与剪辑混音不同步。
- 对白是混音的最高优先级，任何时刻都保证「谁在说」听得清。
- 旁白层单独入轨，与对白不得同时压在同一时刻；冲突时错开或调整覆盖范围。
- BGM 可选，轻柔的谈话节目背景音；对话时压低音量，避免在说话声下出现冲突的音符。

## 剪辑节奏

- 收紧镜头之间的停顿，保持谈话节奏；大段空白留着会让访谈显得拖沓。
- 节奏平淡时加入反应镜头插入——听者点头、微笑、皱眉，是访谈最重要的呼吸口。
- 镜头覆盖在双人镜头、越肩镜头与发言者单人镜头之间交替，同一段落不长时间停在同一种景别。
- 相邻镜头若跳轴，插入正面或过肩过渡镜，不强行拼接。

## 口型与音频对齐

- 对话镜头的口型已由音频驱动生成，剪辑时不得改变播放速度或时间戳。
- 两个对话片段之间若出现空白，用最合适的反应镜头填补，不用变速去凑。

## 常见失败与修复

| 现象 | 原因 | 修复方向 |
| --- | --- | --- |
| 听不清谁在说话 | 音色区分度不足 | 回改音色设计后重出对应音频与镜头 |
| 语音重复或与画面不同步 | 视频层音频未静音 | 静音视频层，改由音频层主控 |
| 口型与音频脱节 | 剪辑时改了速度或时间戳 | 恢复原速原位后重排 |
| 画面单调 | 镜头覆盖未交替 | 补双人、越肩与单人镜头的交替 |
| 访谈节奏拖沓 | 镜头间停顿未收紧 | 收紧停顿，必要时补反应镜头 |
| 说话人脸部太小口型崩 | 关键帧构图过宽 | 重出更近的关键帧后重生成 |
| 出现自带音乐或字幕 | 视频提示词缺负面约束 | 补 no music、no subtitles 后重生成 |

## 导出基准

- 画幅、分辨率与帧率继承全局预设。
- 导出前完整过一遍：每位发言者是否听得出来、对白是否全程清晰、视频层音频是否全部静音、旁白与 BGM 是否越界抢话、片中有无字幕残留。
- 组装与导出由用户在工作台操作，本 Skill 逐步引导核对。
