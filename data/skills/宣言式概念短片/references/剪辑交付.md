# 剪辑交付

> 剪辑以旁白为骨架，音乐是先决条件，波形分析必须先于排布。

## 排布顺序

- 先排定每句旁白的入点与出点，再把对应关键帧、视频挂到该时间窗上；画面比旁白早硬切零点二到零点五秒。
- 必须先完成波形强弱拍与和弦转折分析，再动剪辑线；没有分析结论就不排。
- 轨道结构：主视频轨硬切、禁默认转场；旁白轨到帧；音乐轨单条。

## 音画共振

- 画面硬切对齐 BGM 的重拍、和弦变换或鼓点。
- 断句与重拍冲突时，切点服从音乐。
- 高潮与织体转折处放全片最具异化张力的核心静帧。
- 关键句前留零点五到一秒静默、句后留一到两秒；镜头独占，不跨句做过渡。

## 波形级处理

- 禁粗暴硬断。BGM 在零交叉点与小节边界拼接——休止、和弦渐弱或过渡空隙处。
- 超长则在小节边界做短淡出，或卡拍硬切入尾板前的静音区。
- 旁白缝合避开断音与电爆，交界处做极短交叉淡化。

## 混音电平

- 旁白为唯一清晰基准；念白进行时音乐避让压低，念白静默段（非音乐静默）音乐抬升到接近旁白电平的位置；关键句前后压到近乎全静或全静。
- 所有升降与避让都做短过渡，不硬切音量。
- 尾板前半秒到一秒留静默余响；默认保留音乐作底，末句结束即切断、留全黑全静。
- 时长到点（等于旁白跨度加头尾无人声段）硬切全黑，不做淡出。

## 变速

- 默认不变速；关键镜头可降低到慢速档；禁止加速。
- 视频原始音频全部静音，一切声音都必须是被设计过的。

## 常见失败与修复

| 现象 | 原因 | 修复方向 |
| --- | --- | --- |
| 画面比旁白慢半拍 | 未按入点挂画面 | 按旁白句入点重排，画面提前硬切 |
| 切点与重拍打架 | 未做波形分析或切点优先于音乐 | 先出波形强弱拍结论，冲突时切点服从音乐 |
| 出现转场花活 | 用了默认转场 | 全部改硬切 |
| 音乐盖住旁白 | 混音电平未避让 | 按念白进行与静默两档重做避让 |
| 结尾仓促 | 未留终止静默 | 补片尾无人声段，静默落在结束前半秒到一秒 |
| 画面出现文字 | 提示词缺文字负向约束 | 补负向并重出该帧与视频 |
| 视频自带声音与音乐打架 | 未静音视频原始音频 | 逐镜静音视频层音频 |
| 文案念不顺 | 未念出声校呼吸 | 回文案层重写断点，不靠变速掩盖 |

## 导出基准

- 画幅与分辨率按制片规格锁定值显式携带，关键帧分辨率与终片一致。
- 导出前完整过一遍：每句旁白是否落在对应画面时间窗内、硬切是否对齐重拍、音乐是否在终止静默处干净收束、全片是否有任何文字出现、视频层音频是否全部静音。
- 交付时说明主时钟（旁白实际总时长）与头尾无人声段各自的长度，便于用户核对片长口径。
