# 剪辑交付

## 剪辑节奏与过渡

- 按分镜与时间轴顺序组装所有镜头、旁白轨与 BGM，不自行调换镜头次序。
- 长镜头内部剪辑的各段落之间保持景别纯净与动作意图单一；跨镜头处优先硬切，跳轴时插入正面或过肩过渡镜。
- 切点跟随故事节奏与台词落点；台词说完后保留落点停留，不把停顿剪掉。
- 转场以硬切为主，情绪转折处可短暂用叠化或黑场，避免花哨特效。

## 音频混音层级

- BGM 低于人声与旁白，作为底层垫乐；情绪高潮段落可适当提升。
- 旁白轨与台词不得在同一时刻重叠，冲突时错开排布或调整覆盖范围。
- 音效紧贴对应动作，不与人声抢频段。
- 音色锚点决定的角色音色在成片里必须逐镜一致，发现某镜音色漂移，回到该镜重新绑定锚点后重生成，不靠后期变声补救。
- 台词与音效已内嵌在视频轨，组装不重复叠加。

## 常见失败与修复

| 现象 | 原因 | 修复方向 |
| --- | --- | --- |
| 角色音色跨镜不一致 | 该镜未绑定音色锚点 | 补绑音色锚点后重生成该镜 |
| 台词被改写或情节被改 | 分镜越权创作 | 回改分镜严格对齐剧本原文 |
| 画面出现自带音乐或字幕 | 视频提示词缺负面约束 | 补 no music、no subtitles 后重生成 |
| 节奏拖沓或跳跃 | 长镜头内段落划分与故事节拍不符 | 重排内部剪切顺序与节奏 |
| 关键帧与元素图风格不符 | 关键帧参考不足 | 补绑元素图重出关键帧 |
| 旁白与台词撞车 | 音频层范围重叠 | 调整覆盖范围或错开时间 |
| 音色参考文件无法使用 | 格式不支持或解析失败 | 请用户重新提供，不伪造绑定 |

## 导出基准

- 画幅、分辨率与帧率继承全局预设。
- 导出前完整过一遍：镜头顺序、台词是否与剧本逐字一致、音色是否逐镜一致、旁白与 BGM 是否清楚分层、片中有无字幕与自带音乐残留。
- 能力边界要向用户交代清楚：本流程产出的是音频规划与绑定关系，语音文件不在本流程承诺范围内。
