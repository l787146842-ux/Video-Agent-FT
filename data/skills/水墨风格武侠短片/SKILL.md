# 水墨风格武侠短片

## 一、目标、输入与交付

本 Skill 把用户的武侠剧情或构思做成水墨写意风格的短片：泼墨写意山水为底，矿物泼彩为色，五行特效为武打语言，书法大字为节拍记号。链路为：剧本与素材分析 → 制片规格 → 故事板（含五行元素、四宫格场景、打斗分镜、书法大字卡）→ 设定图与音色资产 → 逐镜视频 → 音频 → 按武打律动组装。

输入包括：剧情或构思、角色人设图、场景参考图、动作视频参考、配音样例、输出语言偏好。用户提供的参考图会先做格式与画风判定：是不是标准三视图、是不是无人物四宫格场景图、笔触与泼彩配比是否合水墨武侠。判定结果决定后续是直接绑定、重构还是原创补全。

交付是按故事板顺序组装、音画同步的短片。生成渠道、模型、分辨率、时长一律以全局设置为唯一权威，本文档不写死这些参数；本 Skill 的责任在时间线合成与导出完成时结束。

## 二、项目结构规划

- 「关键元素」分组登记角色、场景、关键道具：角色挂水墨三视图与声音凭证，场景挂无人物四宫格参考图，道具挂材质图；角色按五行色彩体系编码。
- 有序序列按叙事组织 shot，每个 shot 是序列下一个分组，对应一次视频生成任务；书法大字定格卡作为独立短镜插在关键高潮点或人物首次登场处。
- 「音频」分组管理 audio_layer：BGM、环境音、打击与相克音效、旁白各占独立音频资产，登记覆盖镜头范围。
- 剪辑按故事板顺序组装时间线并完成输出。

## 三、制片规格

把全局制作参数写入 制片规格.md（走 document_write）：画幅比例、目标时长、水墨武侠风格定位、配音与字幕语言，以及从素材分析得出的风格规范——矿物颜料配比、线条笔触特征、泼墨与飞白的比例。这些规范是后续故事板与所有提示词的共同前提。

参数确认后低变化；阶段进度与审核状态留在创作流程管理，不写进规格。任何阶段不得静默改动制片规格。

## 四、创作流程规划

**启动协议**：先确认三件事——现有素材（剧本、人设图、场景图、动作参考、配音样例）、输出语言偏好、本片的水墨武侠风格定位。若用户只给了一句想法，先引导其把人物、门派立场与核心冲突说清楚，再进入规格。

1. 分析输入素材：判定人设图与场景图的格式与画风，提取人设特征、场景四宫格各格内容、矿物颜料配比、线条笔触风格；有动作视频参考时提取攻击前摇、出招、打击点、收招的节奏参数。结论沉淀进 制片规格.md。
2. 设计故事板：登记关键元素（五行编码的角色、四宫格场景、关键道具），拆解 shot 列表，规划打斗分镜与书法大字卡，规划 audio_layer。
3. 绑定或补全资产：用户素材符合规范直接绑定；格式或画风不符先走图生图重构成标准三视图与无人物四宫格；完全没有则原创生成。规则见 `references/媒体生成.md`。
4. 资产闭环自检：逐一核对故事板里每个关键元素都已生成并绑定资产，漏一个就补一个，全部对齐后再开视频生成。
5. 逐镜生成视频：每镜绑定角色图与场景四宫格，有台词时绑定该角色声音凭证；提示词与分镜逐项对齐后才能发单，规则见 `references/提示词写作.md`。
6. 生成音频：角色配音与声音凭证、古典说书人质感的旁白、中国传统器乐为主的 BGM、环境音与打击相克音效。
7. 按武打律动组装时间线：卡点、闪白、定格、频带避让、唇形对齐按 `references/剪辑交付.md` 与 `references/武打剪辑律动与多轨音效设计参考.md` 执行。

**依赖关系：** 2→1；3→1,2；4→3；5→4；6→2；7→5,6

**何时暂停：** 每个阶段完成必须暂停等确认，不一口气输出全部步骤。重点节点：素材分析完毕（报告格式判定与画风结论）；故事板输出后（确认情节与分镜）；每一批资产开始生成前（展示生成计划与提示词或参考关系）；所有图像资产绑定自检后（展示完整绑定关系）；全部镜头视频生成后（进入组装前）。暂停走 workflow_pause，不得声称用户已经同意。

**生成前必须摊开计划：** 任何新资产（元素图像、逐镜视频、音频）开跑前，先告知用户接下来生成什么、用什么提示词、绑哪些参考，得到许可再动手。

**异常处理：** 默认视频渠道因权限或故障报错时，不擅自换模型，暂停任务把报错如实反馈用户，由用户决定。素材分析结论与既有设定冲突时，先向用户确认再改。

**信息缺失处理：** 剧本未写明的人物长相、场景细节、影像风格一律询问，不静默假设、不擅自补全。

## 五、专业创作方法

**全局风格定位：** 背景是张大千式的大气泼墨写意山水，人物走工笔细线与写意泼彩结合的路子，动作靠焦墨枯笔与飞白排线出筋骨。廉价 3D、普通日漫、西式水彩都在负面排除清单里。色彩基底是宣纸的黑白灰与焦、浓、重、淡、清五色，叠加高饱和矿物泼彩（石青、石绿、朱砂、赭石、矿物金）。

**五行色彩编码（人设与特效共用）：** 角色按五行定代表色与战斗语言——金行是亮白锋刃、流金碎屑与焦墨铁骨；木行是狂草藤蔓、翠绿能量流与洒金飞叶；水行是深蓝泼墨、高粘滞流体与极寒冰刃；火行是朱砂熔金烈焰配焦墨骨架；土行是枯笔飞石、赭石扬尘与自发光大地裂纹。每个元素的爆发态要写明色彩明暗配比、运动物理质感、微观光影渲染三层，完整双语词库见 `references/五行特效与爆发态提示词库.md`，此处只守口径：**爆发态必须有明确的百分比配色、有介质层面的物理质感、有可指认的光源方向**，三者缺一即视为空泛描述。

**笔法张力随动缩放（核心铁律）：** 画风跟镜头动能绑定。静态或慢速运镜（文戏、意境空镜、微速推拉）用精细工笔勾边、线条纤细匀称、墨色温润清雅、保留宣纸纹理；极速运镜或强力打击（急推、急扫、命中、爆发瞬态）画风瞬间蜕变为粗犷狂乱的焦墨枯笔与飞白排线，线条加粗、边缘干裂、喷溅黑墨点。同一部片里两种笔法必须由镜头动能决定切换，不能随手混用。

**色彩比例分档：** 意境空镜与文戏采用国画构图配比——工笔细描约三成半到四成、意境留白约三成半到四成、古典泼彩仅两三成点缀在远山竹林飞瀑，墨色晕染分层，光影柔和无硬边；常规对打与文武过渡用均衡比例，黑白灰与泼彩各半，用一束强光穿透焦墨阴云在战场中央破开呼吸感；高潮决战与五行大冲撞用色彩主导加浓墨压阵，七彩大面积泼洒碰撞但必须用焦墨宿墨勾住结构，防止色彩过载变廉价。

**角色设定：** 面部微表情分两套口径。日常与对峙的文戏用极细腻写意的微表情——眉尖微蹙、眼波流转、下颌线紧绷，靠匀称工笔细线托出温润古意；大招碰撞、爆发、受击瞬态必须给足生理与情感张力——咬牙、咬肌剧烈收缩、太阳穴青筋突起、瞳孔缩至针尖或迸出五行异彩。大汗、泪、血一律水墨化处理：半干宿墨的干枯血泪痕、顺面部骨骼炸开的飞白抓痕、高频喷溅墨点、面部落下焦墨斑块——把情绪爆发外化为宣纸上的笔墨撕裂。

**台词与唇形：** 武侠台词用精简有力的短句，单句短到能让生成引擎吐完并留下唇形闭合的余量；显式标出停顿与呼吸口。带台词的镜头必须让说话角色处于特写或中景，让观众看清唇部肌肉开合。

**场景设定：** 一律用无人物四宫格参考图，四格内容固定——全景定场交代地貌天际线，陈设特写展现古松石碑案几的微观水墨质感，纵深透视给出前景中景远景的层次与透视线，气氛光效规定主色调晕染范围与明暗对比。经典陈设要写成可渲染的水墨物理：劲松用粗砺顿挫的焦墨枯笔扫出开裂鳞皮、松针用工笔排线聚拢；孤碑用淡墨湿晕打底再以干焦笔勾裂隙、碑面用石青朱砂点苔；竹林远景湿墨虚化、近景中锋干笔挺拔、竹叶用「个/介」字撇叶法带毛锋飞白。

**shot 时长与节奏：** 每镜时长必须按动作激烈程度、信息量与台词字数显式设定，取全局设置里的档位。极速打斗、瞬发切招、特写用较短档；连击、招式死锁、大招对碰用中间档，给多段打击与粒子爆散留生长时间；台词对白、蓄势文戏、写意空镜、吐息大爆轰用较长档，给唇形对齐与云雾舒展留呼吸。绝对不要全片套同一个默认时长。

**场景强绑定（防跳画）：** 每镜必须显式声明所属场景元素 ID，没有场景归属的镜头视为缺陷。相邻镜头在同一地点或属于同一打斗/对话回合时，场景 ID 必须完全一致，下游据此复用同一张四宫格资产，从分镜源头根除背景突变。

**打斗分镜按流派分级：** 人类角色是武侠写实、拳拳到肉；妖兽角色是魔幻夸张、肉身突变、非线性轨迹、撕裂地貌；五行使者是虚实结合、法术与真武术并重，并写明该行招式的具体呈现形式。

**各流派招式分镜规则：** 拳脚连击——单击给肌肉紧绷特写配气劲水墨波纹，多段连击用快慢交替的硬切与画幅震颤，最后一记终结重拳才给重定格。轻功——极低仰角跟随腾空，背景山水向下坠落凸显高度，空中滞留用微慢动作，滑行轨迹画写意风迹残影。暗器——先给手指发力极近特写，再急扫或主观视角追踪轨迹，飞行时画银白锋芒速度线，命中处硬切爆发特写。刀剑格挡与死锁——刀刃相接火花飞溅的极近特写或硬切闪白，随后是双方额角青筋、眼神死咬、兵刃高频颤抖的角力微观张力。太极气功与柔拳——起招蓄势用连续慢速圆形行掌配极慢环绕，出手瞬间镜头突进硬切，气劲压缩成巨大写意气浪，背景震出写意波纹。身法瞬移与高速位移——起步前给蓄力下蹲特写，瞬移瞬间原位留透光水墨残影、本体在新位置凝结，背景在位移轴线上拉伸合拢。妖兽——躯体突变用倾斜地平线与广角畸变，撕裂抓击用锯齿状非线性轨迹与破空墨痕，且每次命中都要给场景实体碎裂的画面特写。

**五行相克与转场：** 交战双方招式必须形成强色彩反差（蓝色冰浪对冲赤红烈焰、朱砂火海吞噬翠绿飞叶），用泼彩的覆盖性表达克制关系。克制转场要有具体画面语法：水克火是泼墨巨浪扑灭烈焰并炸出大范围白色蒸汽，火克木是烈焰沿藤蔓像墨汁在宣纸上蔓延、把飞叶碳化成焦墨碎屑，木克土是狂草藤蔓穿裂枯笔巨石并在裂缝长出绿叶，土克水是枯笔巨石拔地截断水流或沙尘吸干水墨，金克木是金色锋刃横扫、断口爆出漫天洒金。致命一击或大碰撞处安排黑白水墨闪（Impact Frame）做硬切转场。

**标志性镜头语言：** 黑白水墨闪——瞬间切成纯黑白、只留粗犷硬朗的水墨线条爆发力量，用在打斗高潮与大碰撞帧。急推——从全景中景瞬间硬拉至双眼、紧绷肢体或刃口咬合的特写，配极速突进与高频聚拢音效。急拉——从极近景瞬间拉远到远景，拉出碎石瓦解与风沙席卷的威压，配低频空间音效排开。急扫——沿施力方向高速横纵扫掠，背景笔墨高速失焦化成写意流线，焦点死锁在动能切线。多段连击的硬切必须做到动能矢量轴线对齐，切点锁在惯性最大的那一帧；大跨度身法切换处用多重水墨残影与笔锋刮擦拖尾桥接视觉缝隙。

**碎落粒子与烟尘：** 受击飞退、大招碰撞、兵刃碎裂处必须规划写意碎落粒子——矿物泼彩碎屑、金箔金粉、枯笔飞白屑末；烟尘一律用粗粝的焦墨烟云、飞舞的炭尘、燃烧的宣纸黑灰，边缘带焦边与飞白刮痕。均质发光的魔法数字粒子不在口径内。

**书法大字定格卡：** 关键高潮点或人物首次登场处，规划一个独立的短时长特写镜：巨大狂野的传统书法大字直接在宣纸上震裂爆开，背景是焦墨飞白抓痕、泼彩炸裂与宿墨渗透晕开，画面中不出现其他人物，主题字写在画面中心。

**非战斗意境镜头：** 文戏、空镜、独白、情绪过渡处安排诗意慢镜——远山如黛、层峦叠嶂、烟雨朦胧、大面积留白。文戏长镜头的平移要像长卷缓缓展开，镜头速率写成微速平缓，画面边缘的焦墨重彩随平移徐徐隐现，云雾在画面中央做呼吸式扩散。抒情与蓄势处安排慢推的国画陈设特写，焦点锁在孤碑残刻、劲松虬枝、竹叶上滑落的一滴水墨。意境之间的过渡用墨滴晕染或飞白拖尾，写明墨汁如何在宣纸上渗开、笔锋如何扫出枯笔纹理并演变成下一镜的环境。

**audio_layer 设计：** BGM 以古筝、二胡、笛子为骨，可融入重打击乐与电子摇滚元素，为高潮大冲撞预留重音卡点与听觉留白气口。环境音铺中式写意底噪——风过竹林、细雨拍叶、纸张沙沙、墨滴融开，随文武戏转换呼吸强弱。打击音效分两类：常规武招给刀剑击鸣、肉体闷击、轻功风掠；五行克制大碰撞按碰撞类型做双层叠加（如金克木是金属割裂加草木断裂复音，水克火是怒涛拍击加高压蒸汽嘶鸣）。旁白用沉稳浑厚、有宿命沧桑感的古典说书人老者声线。
