# 剪辑交付

> 组装阶段只做时间线层面的切点、定格、声画对齐与频带避让；武打律动与多轨音效的完整时值、卡点、频带参数另有专册，本册给通用骨架与底线口径。

## 打斗剪辑的底线口径

- 战斗剪辑节奏极度紧凑，常规攻击动作快速短切。
- 招式交汇的绝对瞬间执行黑白水墨闪硬切，配一到数帧微重力定格。
- 音效采用双层叠加结构：高频特征层（根据交战双方属性写实合成）+ 低频能量层（超重低音与空气激波）。
- 碰撞瞬间 BGM 执行频带削峰避让，给标志性音效腾出频带。
- 出现对白或旁白时，环境音与打击音效主动下压、高通削弱低频，BGM 提前瞬态下压、结束后平滑恢复。
- 对白波形起步瞬态与画面口型首帧毫秒级对齐，允许极微弱的人耳无感偏差；台词结束时口型同步闭合。

详细时值、卡点、频带避让参数见 `references/武打剪辑律动与多轨音效设计参考.md`，组装前必须先加载并严格遵循。

## 剪辑节奏与过渡

- 按故事板 shot 顺序组装；同一物理空间内相邻 shot 优先无缝硬切，避免滥用转场。
- 相邻镜头如果跳轴，插入正面或过肩过渡镜，不强行拼接。
- 文戏与意境镜头保持长时值，动作镜头保持短时值，两者之间不拉平均。
- 意境转场用墨滴晕染或飞白拖尾，不用软件自带的线性淡入淡出；墨晕取前慢后快的自然渗透曲线，飞白取快速笔扫并带纸张质感遮罩。
- 黑白水墨闪、闪白帧、定格帧这些节拍点必须先对齐好，再往里塞音效，不能反过来用音效盖住画面缺陷。

## 音频混音层级

- 环境音在文戏与蓄势留白镜头保持常态音量、宽立体声；武打或急速运镜启动的瞬间瞬态下压并向中心声道收拢，让焦点迅速集中到打击音效与重节奏 BGM。
- 打击音效的启动时间保持极短，保证撞击的硬度与穿透力；水墨流体、火焰爆裂这类法术尾音用平滑的指数衰减，留下笔墨扩散的余韵。
- 五行克制大碰撞的音效与 BGM 重拍精准合拍；定格瞬间给短时听觉真空，定格释放时重鼓点爆发式切回。
- 对白与旁白在场时，音效层下压并高通削弱低频，BGM 提前下压、结束后平滑恢复。
- 台词与音效已在视频轨内嵌，组装时不重复叠加同类音频。

## 常见失败与修复

| 现象 | 原因 | 修复方向 |
| --- | --- | --- |
| 生成出四宫格或分屏画面 | 未写防分屏声明 | 补写四格内容声明与防拼贴指令后重生成 |
| 背景跳画、前后场景突变 | 相邻镜头场景 ID 不一致或场景图重复生成 | 统一场景 ID 并复用同一份四宫格资产，重生成该镜 |
| 口型对不上、张合频率脱节 | 未绑定角色声音凭证 | 补绑声音凭证后重生成 |
| 打斗动作读不清 | 全程镜头晃动或时长过短 | 晃动只留命中瞬间，按动作密度调整时长后重生成 |
| 命中缺少打击感 | 只有画面没有节拍设计 | 补微重力定格、闪白与瞬态音效卡点 |
| 火焰、水流像 CG 特效 | 提示词用了 3D 或魔法粒子词 | 换回矿物泼彩、焦墨烟尘等介质词重生成 |
| 画面变廉价 3D 或普通日漫 | 负面排除词缺失 | 补 3D、CGI、写实、西式水彩等排除项 |
| 色彩过载显廉价 | 泼彩比例失衡、缺焦墨压阵 | 回改色彩比例与焦墨骨架描述后重生成 |

## 导出基准

- 视频轨分辨率对齐生成时的最高规格，画幅与帧率继承制片规格的全局预设。
- 需要流畅慢动作的片段单独插帧后再并入时间线，不整片插帧。
- 导出前完整过一遍：黑白水墨闪的帧数是否够、定格是否落在打击点上、对白是否被音效吃掉、片中有无字幕残留与分屏帧。
