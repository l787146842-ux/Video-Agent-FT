# 剪辑交付

## 剪辑节奏与过渡

- 按分镜与时间轴顺序组装所有镜头、旁白轨与 BGM，不自行调换镜头次序。
- 一镜到底工作流的成片，切点来自镜头内部的剪辑标记；组装时保持每段景别纯净、动作意图单一。
- 相邻镜头若跳轴，插入正面或过肩过渡镜；跨场景切点优先硬切。
- 台词说完保留落点停留，不把停顿剪掉；动作做完保留收势，不提前切。

## 音频混音层级

- BGM 低于人声与旁白，作底层垫乐；情绪高潮段可适当提升。
- 旁白与台词不得在同一时刻重叠，冲突时错开或调整范围。
- 台词、音效已内嵌在视频轨，组装不重复叠加同类音频。
- 独立 audio_layer 的 BGM 与旁白按分镜标注的范围入轨，不擅自延伸覆盖。

## 常见失败与修复

| 现象 | 原因 | 修复方向 |
| --- | --- | --- |
| 剧情或台词与剧本不符 | 分镜越权改动 | 回改分镜严格对齐剧本原文 |
| 未经确认就开生成 | 跳过了草稿闸门 | 停止生成，补草稿并取得确认后重来 |
| 单镜超时被截断 | 分镜时长超全局设置 | 拆镜后重生成，不靠裁切硬拼 |
| 人物跨镜漂移 | 元素图未绑定或视角不全 | 补绑元素图与多视图，重生成该镜 |
| 出现自带音乐或字幕 | 视频提示词缺负面约束 | 补 no music、no subtitles 后重生成 |
| 旁白与画面冲突 | 视频提示词写了旁白文本 | 删除该段文本，改由独立音频轨承载 |
| 音色跨镜不一致 | 未传入角色音色参考 | 补传音色参考并明确对应关系后重生成 |

## 导出基准

- 画幅、分辨率与帧率继承全局预设；导出前确认总时长与规范一致。
- 导出前完整过一遍：剧情与台词是否与剧本逐字一致、单镜时长是否合规、旁白与 BGM 是否清楚分层、片中有无字幕与自带音乐残留。
- 交付时如实说明每一步的确认记录，不把未经确认的生成说成已确认。
