# 媒体生成

> 渠道与模型一律以全局设置为唯一权威。本分册另外守着一条硬闸门：**没有确认过的提示词草稿，不得开生成。**

## Prompt Draft 闸门（强制）

- 每条提示词先以草稿形态展示给用户：资产类型（元素图或镜头视频）、对应的元素 ID 或镜头 ID、完整提示词文本、推荐渠道与参数。
- 分两批走：先元素图草稿，确认后生成元素图；元素图完毕后再镜头视频草稿，确认后生成视频。
- 未获确认不得调用生成；不得默认跳过草稿；不得把「用户没反对」当作确认。用户提修改就先更新草稿再确认。
- 用户已上传且可直接绑定的资产不需要写草稿，直接绑定即可。

## 元素图生成

- 用户已为元素指定资产（角色图、产品图）时直接使用，不生成。
- 其余角色、场景、道具走文生图；同一角色多种状态走图生图，参考第一张以保持一致。
- 角色建议用多视图以支撑跨镜一致性，每个视图单独注册资产分别生成；一张横向角色图里从左到右放半身特写加全身三视图（正面、侧面、背面），便于下游读取身份与服装信息。
- 用户提供的参考媒体被指定为关键元素时，描述必须与所见内容一致。

## 分镜表格图

- 需要时用分镜表格图确认镜头逻辑，登记到对应 shot 的图像资产；只供用户确认，不作视频生成的参考输入。

## 镜头视频生成

- 多模态参考通道，模型与分辨率按全局设置。参考该镜的元素图像；若项目里有生成或上传的角色音色参考，一并作为参考传入，并明确哪个角色用哪段参考音频。
- 只在当前镜头与前一镜的物理连续性极强时，才追加上一镜成片作视频参考。
- 有独立旁白轨时，视频提示词里不写旁白文本，避免与音频轨冲突。
- 时长必须按全局设置执行，超限拆镜，不能靠剪辑裁切弥补。

## 音频生成

- 旁白：内容、声音、语调与时间严格按分镜执行；有音色参考资产时生成时对齐。
- BGM：风格与节奏跟最终视频规范或参考匹配，时长与范围按分镜执行。
- 台词与音效随视频内嵌，独立音频层不重复叠加同类内容。

## 首尾帧衔接

- 首镜以元素图确立画面基准；后续每镜以上一镜末帧或该镜关键帧为视觉起点。
- 衔接不上时回改故事板锚点或调整本镜开场，不靠裁切硬拼。

## 失败与降级

- 视频渠道不可用时暂停说明现状，不擅自换通道。
- 元素图偏离剧本设定时重出该资产，不带着错误资产生成视频。
- 草稿被退回时，只改用户指出的部分，不顺手重写整条提示词。
