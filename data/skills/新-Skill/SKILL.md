# 剧本生视频（需上传剧本）

## 一、目标、输入与交付

本 Skill 把用户上传的剧本做成完整视频。它与其他剧集类 Skill 的关键差别在两点：一是**一镜到底工作流**——优先用含内部剪辑的长镜头承载叙事，而不是切成一堆短镜；二是**Prompt Draft 强制前置**——所有图与视频的生成都必须先有一份被用户确认过的提示词草稿，跳过草稿直接生成属于违规。

输入包括：剧本文件（图片、PDF、文本任一种，必须提供）、用户已有的元素资产（角色图、产品图等，可选）、音色参考（可选）、输出语言与视觉风格偏好。剧本是唯一剧情权威来源，对话、旁白、动作结果与场景顺序一律以它为准。

交付是按分镜顺序组装、音画同步的成片。生成渠道、模型、分辨率、时长一律以全局设置为唯一权威，本文档不写死这些参数；剪辑与导出由用户在工作台完成，本 Skill 引导。

## 二、项目结构规划

- 「关键元素」分组登记关键主体、关键地点与场景、关键道具，每个实体一个稳定元素 ID。
- 有序序列按剧本场景顺序组织镜头，每个镜头是序列下一个分组，对应一次视频生成任务；优先在单镜内部设计剪辑与情绪起伏。
- 「音频」分组管理 audio_layer：BGM 至少一条全局轨，剧本含旁白或对话时设计 narration 条目并写明内容、声音语调与时间范围。
- 每个镜头的提示词先以草稿形态存在，确认后才转为生成指令。

## 三、制片规格

把全局制作参数写入最终视频规范文档（走 document_write）：标题、类型、画幅比例、时长、视觉风格、输出语言、渠道偏好。这份规范是后续所有提示词的共同前提，与剧本一起构成双重约束：格式听规范、内容听剧本。

## 四、创作流程规划

**启动协议**：确认剧本已上传且可解析，一句话总结剧本故事并请用户确认理解无误；确认输出语言、视觉风格、是否需要音色参考。理解有偏差先纠正再往下走。

1. 一句话总结上传剧本的故事，确认理解正确。
2. 写最终视频规范文档，锁定全局参数。
3. 生成与剧本相符的故事板：关键元素、镜头列表、音频层。
4. **Prompt Draft 编制与确认（生成前的强制前置）**：把每条提示词以草稿形式展示给用户，每份草稿包含资产类型（元素图或镜头视频）、对应的元素 ID 或镜头 ID、完整提示词文本、推荐渠道与参数。**分批确认**：先编元素图草稿，确认后才生成元素图；元素图完毕后再编镜头视频草稿，确认后才生成视频。用户提出修改时先更新草稿再确认，通过后才能执行。
5. 设置元素：用户已上传的角色图、产品图等直接绑定，不重生成；其余按确认过的元素草稿生成图像。
6. 逐镜生成视频：严格参考该镜的元素图，在镜头视频草稿确认后执行；有音色参考时一并参考。
7. 按故事板生成所有音频层。
8. 全部资源就绪后剪辑，引导用户导出。

**依赖关系：** 2→1；3→1,2；4→3；5→4；6→4,5；7→3；8→5,6,7

**何时暂停：** 不要一次性跑完。每个关键阶段后停下与用户确认再继续：规范确认后、故事板生成后、**Prompt Draft 确认后**、元素图像生成后、镜头视频生成后、音频生成后。用卡片或 workflow_pause 邀请审阅，不得声称用户已经同意。

**草稿闸门的硬口径：** 未获确认不得调用生成；不得默认跳过草稿直接生成；不得把「用户没反对」当作确认。用户已上传且可直接绑定的资产不需要写草稿，直接绑定即可。

**用户已有媒体优先：** 用户提供或项目里已有的媒体，先绑定并分配到合适的分镜位置，再考虑生成，避免重复生成已有内容。

## 五、专业创作方法

**剧本忠实度（最高优先级）：** 分镜中的对话、旁白、动作结果与场景顺序必须与上传剧本及分析结论一致。只允许技术性编辑——拆分镜头、补充镜头语言字段；不得虚构情节或改写台词。剧本省略了镜头覆盖范围时，可以按类型与基调专业地推断构图与运动，但绝不改变情节事实与对话。

**一镜到底工作流：** 倾向使用含内部剪辑的长镜头，在镜头内部设计剪切与情绪起伏，而不是拆分为许多短镜；剪辑频率跟随故事节奏。单镜时长必须落在全局设置的区间内，超限必须拆分。有内部剪切时，在场景与设定之后按剪辑顺序排列故事内容与镜头语言，用明确的时间与剪切标记衔接，让每个段落只承载单一景别与单一动作意图。

**元素设计：** 角色描述写清面部特征、发型、妆容造型、服装配饰的材质版型颜色与状态，并登记声音与音色；同一角色有多个状态或外观时并列写明。场景描述写清重要物件的位置与朝向，特别是道具与主要动作发生区域。用户提供并指定为关键元素的资产，描述必须与其所见所闻一致，不得矛盾。

**镜头描述三件套：** 每个镜头必须写清场景引用（场景元素 ID）、故事与表演（含确切台词，口语对话或内心独白、画外音都写原文）、镜头语言（景别、角度、运动），三者缺一不可。

**声音设计：** BGM 至少一条全局轨，风格节奏跟参考或规范匹配；有明显节奏或情绪变化时拆分片段并各自定义范围。剧本有旁白或对话时在音频层设计 narration 条目，写明内容、声音语调与时间范围，有音色参考资产时链接到对应排布说明上便于对齐。

**提示词的语言口径：** 用户在中文环境或有中文输入时，提示词用中文书写；但提示词里的旁白与对话内容必须严格遵循规范里锁定的输出语言，两者不能混为一谈。
