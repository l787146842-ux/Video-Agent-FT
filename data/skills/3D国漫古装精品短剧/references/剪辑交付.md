# 剪辑交付

> 组装阶段只做时间线层面的拼接、混音与导出；跨镜空间一致性在视频生成阶段已由参考帧机制保障，这里不重复选帧过滤。

## 跨镜空间一致性策略

- 组装时如发现跨镜站位漂移、背景元素与空间锚点卡不符，不靠裁剪掩盖，回到视频生成阶段重新截取参考帧或修正本 shot 空间锚点描述，检查通过后再拼接。
- 同一场景内所有 shot 的光影基调须与该场景元素的固定光影基准逐字一致，剪辑阶段不做「统一调色」式补救——调色只用于全片整体影调收口，不用于修补单镜光影错误。

## 剪辑节奏与过渡

- 按故事板 shot 顺序组装。对话密集段落保持紧凑，情绪特写给足呼吸时间，避免把停顿剪掉。
- 同一物理空间内的相邻 shot 优先无缝硬切；跨空间切换可用淡入淡出（0.3s 以内），避免滥用转场特效。
- 180° 轴线：若相邻两 shot 出现跳轴，在中间插入一个正面或过肩过渡 shot，而不是强行拼接。
- 台词与动作的落点停留是节奏的一部分——剪辑时不要把已生成的停留帧剪掉，否则成片会出现「话没说完就跳」的观感。
- 首个 shot 是全片基准，后期调色、音量基准都以它为准，其余 shot 向它对齐。

## 音频混音层级

- BGM（audio_layer）音量低于人声 8—12 dB，作为底层垫乐；情绪高潮段可适当提升 3—5 dB。
- 台词、音效、内心 OS 已内嵌在视频轨中，组装时不额外叠加同类音频，避免重复。
- 第三人称旁白（narration audio_layer）音量与台词层平齐，在时间线上与对应 shot 对齐。
- BGM 与旁白、台词交叉淡化（crossfade 0.5s），防止硬切产生音量跳变。
- 内心 OS 走角色专属音色通道，混音时与台词同层；OS 段不要另铺旁白，避免两条画外音叠在一起。

## 常见生成失败与组装修复

| 现象 | 原因 | 修复方向 |
| --- | --- | --- |
| 角色外貌跨 shot 漂移 | 提示词角色描述不够具体 | 在提示词中强化设定图特征词，重新生成该 shot |
| 角色声线跨镜不一致 | 台词或 OS 走了通用声音通道 | 重新绑定该角色的音色样本，重生成该 shot |
| 跳轴 | 相邻 shot 机位跨过 180° 轴线 | 插入正面或过肩过渡 shot |
| 镜头时长偏差 | 模型对绝对秒数不敏感 | 改用 slow / quick / lingering 节奏词，组装时用时间线裁剪微调 |
| 台词说完即切 | 提示词缺少台词落点停留描述 | 补一句落点表情延续，重生成该 shot |
| 动作仓促收尾 | 动作缺少收势与停留 | 补完整起势—执行—收势与停留，重生成该 shot |
| 背景元素与锚点卡不符 | 参考帧背景不匹配或锚点描述有误 | 回溯修正参考帧或空间锚点卡，重生成 |
| 出现全景或大全景 | 分镜设计越界 | 回改分镜景别后重生成，不靠裁剪放大补救 |
| 现代元素乱入 | 提示词未写禁止项 | 强化禁止现代元素的尾部规则，重新生成 |
| 字幕乱入 | 视频提示词未明确禁止 | 强化 no subtitles, no text overlay，重新生成 |
| 首尾帧不衔接 | 上一 shot 末帧人物已偏离空间锚点 | 将本 shot 第一个内切镜设计为过渡镜，引导画面回到锚点 |

## 导出基准

- 视频轨分辨率对齐生成时的最高规格；如需提升，经超分通道上采样后再导出。
- 帧率按全局设置；如需流畅慢动作片段，对目标 shot 单独执行帧插值后再并入时间线，不要整片插帧。
- 导出前完整过一遍成片：对白是否清楚、OS 是否与口型冲突、BGM 是否压过人声、有无字幕残留与黑帧。
