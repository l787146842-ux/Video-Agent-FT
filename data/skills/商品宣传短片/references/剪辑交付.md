# 剪辑交付

## 组装顺序

- 按已确认故事板的时间轴执行：先核对每个镜头视频与音频层都已就绪，再按分镜序号依序装配；缺失资产先回补，不带缺口进入组装。
- 组装与导出由用户在工作台操作，本 Skill 逐步引导核对；导出前用 workflow_pause 请用户做最终确认。

## 商业广告的节奏

- 硬切为主，每次剪辑都要有清晰的视觉变化。
- 短镜头优先；某个镜头必须留长时，靠内部节奏而不是拖慢切点。
- 景别按「建立 → 细节 → 情绪或纹理 → 高潮或包装展示」推进，不要一路同景别平推。
- 相邻镜头若跳轴，插入正面或过肩过渡镜；跨场景直接用硬切，不用花哨转场。
- 包装镜头与 Logo 时长、位置按简报强制要求落实，放在约定位置，不延后不省略。

## 音频混装

- 全局背景音轨贯穿全片；多段 BGM 按各自范围入轨，交叠处交叉淡化。
- 旁白轨用覆盖范围限定在相关镜头，不越界铺满；旁白与音乐冲突处压低音乐层次。
- 台词与音效已在视频轨内嵌，组装不重复叠加。
- 产品镜若有手工拟音需求（开合声、结构声、材质摩擦声），在音效层单独补，不与旁白抢频段。

## 字幕与包装文字

- 字幕与包装文字在后期添加，组装阶段预留字幕安全区，避免压在 Logo 与产品主体上。
- 视频提示词里已经禁掉了模型自带的字幕与文字，出现残留即判该镜需重生成，不靠遮盖处理。

## 常见失败与修复

| 现象 | 原因 | 修复方向 |
| --- | --- | --- |
| 产品外观与素材不符 | 产品元素未绑定或描述越权 | 重绑产品素材，重出该元素与该镜 |
| 成片像产品目录 | 全是主角镜头，缺辅助镜头 | 回改分镜，补功能与氛围类镜头 |
| 成片看不到产品 | 辅助镜头过多或产品镜过弱 | 回改配比，保证产品真实处在环境中 |
| 包装镜头或 Logo 缺失 | 故事板未排入强制项 | 回补分镜并在约定位置落实 |
| 剪辑平淡没有驱动力 | 运镜与景别未交替 | 变换镜头语法，重生成相关镜头 |
| 画面出现自制标识或文字 | 模型自由发挥 | 补负向约束，以元素图锁定包装，重生成 |
| 旁白被音乐盖住 | 混音未避让 | 重新调整电平与覆盖范围 |
| 节奏拖沓 | 用了过长镜头 | 剪短或拆分，恢复硬切节奏 |

## 导出基准

- 画幅与总时长遵循制片规格；分辨率与帧率继承全局预设。
- 导出前完整过一遍：产品外观是否逐镜一致、两类镜头是否交叉、包装与 Logo 是否按简报落位、字幕安全区是否留足、旁白与音乐是否分层清楚、有无模型自带文字残留。
