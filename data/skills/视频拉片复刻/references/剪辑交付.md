# 剪辑交付

## 剪辑节奏与过渡

- 按分镜与时间轴顺序组装所有镜头、旁白轨与 BGM。
- 节奏以拉片结论为基准：平均镜长、切点密度、景别推进方式与转场手段都要向参考视频对齐。
- 相邻镜头若跳轴，插入正面或过肩过渡镜；内部剪辑的段落之间保持景别纯净。
- 转场以硬切为主，对齐参考视频的转场手法；确需软化时用短叠化，不引入原片没有的特效。

## 视频层音频处理（本 Skill 的关键一步）

- 如果该镜本身没有镜头内对话或旁白，**在剪辑中把视频层的嵌入音频静音**，只依赖音频层里按设计使用的 BGM 与音效。否则视频生成的音频会与混音冲突。
- 有内嵌台词或音效的镜头保留其音轨，不再重复叠加同类音频。
- 静音操作要逐镜检查，不要整轨一刀切，避免把需要保留的台词一起抹掉。

## 音频混音层级

- BGM 低于人声与旁白，作底层垫乐；情绪高潮段可适当提升。
- 旁白内容、声音、语调与时间安排严格按分镜执行；有语音参考资产时与之对齐。
- 旁白与台词不得在同一时刻重叠，冲突时错开或调整范围。
- 音效紧贴对应动作，不与人声抢频段。

## 常见失败与修复

| 现象 | 原因 | 修复方向 |
| --- | --- | --- |
| 成片节奏与原片差得远 | 分镜未映射拉片节奏 | 回改分镜的平均镜长与切点密度 |
| 构图与原片不一致 | 关键帧未被引用或引用错帧 | 换用同片段更对应的关键帧重生成 |
| 视频生成的音频与混音打架 | 该镜无对白却未静音视频层 | 逐镜检查并把无对白镜的视频层音频静音 |
| 人物跨镜漂移 | 元素图未绑定或三视图不全 | 补绑元素图与三视图，重生成该镜 |
| 画面出现原片水印或字幕 | 关键帧带着残留信息 | 换干净帧，或提示词中排除残留元素后重生成 |
| 旁白语调与原片不符 | 未使用语音参考 | 补绑语音参考重生成旁白 |
| 出现自带音乐或字幕 | 视频提示词缺负面约束 | 补 no music、no subtitles 后重生成 |

## 导出基准

- 画幅、分辨率与帧率继承全局预设；总时长对齐参考视频的结构而非硬凑。
- 导出前完整过一遍：镜头顺序与拉片片段是否一一对应、视频层静音是否逐镜正确、旁白与 BGM 是否清楚分层、有无水印与字幕残留。
- 交付时说明本片复刻的是参考视频的镜头语言，内容已替换为新主题。
