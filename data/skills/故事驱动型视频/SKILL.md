# 故事驱动型视频

## 一、目标、输入与交付

本 Skill 做故事驱动型视频：叙事推进是第一目的，视觉选择服务于故事。链路为：制片规格 → 故事板（关键元素、镜头列表、音频层）→ 元素资产 → 逐镜视频 → 音频层 → 组装导出。

输入包括：故事或剧本、角色与场景参考图（可选）、音色参考、视觉风格与画幅时长偏好、输出语言。用户提供或项目里已有的媒体一律先绑定使用，不重复生成。

交付是按故事板顺序组装、音画同步的成片。生成渠道、模型、分辨率、时长一律以全局设置为唯一权威，本文档不写死这些参数。

## 二、项目结构规划

- 「关键元素」分组登记关键主体、关键地点与场景、关键道具，每个实体一个稳定元素 ID；角色有多个状态或外观时并列写明。
- 有序序列按叙事顺序组织镜头，每个镜头是序列下一个分组；优先用带内部剪辑的长镜头承载叙事。
- 「音频」分组管理 audio_layer：BGM 至少一条全局轨，长片有明显间歇或转折时可规划多段并各自定义范围；大段旁白解说推进故事时以 narration 登记，写明语音特征、语调与确切脚本，并限定覆盖镜头。
- 剪辑按故事板顺序组装时间线。

## 三、制片规格

把全局制作参数写入 制片规格.md（走 document_write）：标题、类型、画幅比例、时长、视觉风格、输出语言、渠道偏好。规格一经确认即成为后续所有环节的共同前提，阶段进度与审核状态不写进规格。

## 四、创作流程规划

**启动协议**：确认故事内容与题材、目标时长、画幅与视觉风格、是否需要旁白解说、输出语言。故事还不成形时先与用户一起把「谁想要什么、遇到什么阻碍、最后怎样」说清，再进规格。

1. 写 制片规格.md 锁定全局参数。
2. 生成故事板：关键元素、镜头列表、音频层；故事板就绪后扫描上下文，找出用户提供或此前生成的、与故事板条目匹配的资产，在生成前绑定并分配到对应槽位。
3. 设置元素：用户已上传的元素资源直接绑定；其余生成图像资产。
4. 逐镜生成视频：参考该镜相关的所有元素图像；当前镜头与前一镜连贯性极高时，可选地把前一镜成片作为视频参考。
5. 按故事板生成所有音频层。
6. 全部资源就绪后组装，引导用户导出。

**依赖关系：** 2→1；3→2；4→3；5→2；6→3,4,5

**何时暂停：** 不要一次性跑完。每个关键阶段后停下与用户确认：规格定稿后、故事板完成后、元素完成后、镜头视频生成后、音频生成后。用卡片或 workflow_pause 邀请审阅，不得声称用户已经同意。

**用户已有媒体优先：** 用户提供或预先存在的媒体，在生成内容前先绑定并分配到适当的故事板位置，避免重复生成已有内容。

## 五、专业创作方法

**叙事优先原则：** 每个镜头的存在都要能回答「它在故事里承担什么」——推进情节、揭示人物、制造转折或给出情绪落点。回答不出来的镜头就该删掉或改动，而不是靠漂亮画面留着。

**长镜头与内部剪辑：** 优先使用带内部剪辑的长镜头，在镜头内部设计剪切与情绪起伏，而不是拆分成许多短镜；剪辑频率跟随叙事节奏，不追求机械的均匀切点。每个镜头时长按全局设置执行。有内部剪辑时，在场景与设定之后按剪辑顺序列出故事内容与摄影语言，让每段只承载单一景别与单一动作意图。

**镜头描述三件套（缺一不可）：**

- **场景**：引用地点或布景的场景元素 ID。
- **故事内容**：角色与关键物体的动作动态；对话与表演，写出确切台词（口语对白或内心独白、画外音都写原文），角色用元素 ID 引用。
- **摄影**：景别、摄像机角度、摄像机运动。

**元素设计：** 角色描述写清面部特征、发型、妆容造型、服装配饰的材质剪裁颜色与状态，多状态或多外观并列写明；角色要同时登记音色参考，音色样本素材的时长遵循全局设置，避免过长。场景描述写清重要物件的位置与朝向，尤其是道具与重大动作、表演发生的区域。用户提供并指定为关键元素的媒体，描述必须与其一致，不得矛盾。

**角色参考图版式：** 每个角色一张横向并排的参考图——左侧头像（紧凑构图，聚焦面部，用来确认身份、肤色、眼睛与发际线），右侧全身照（展示服装、发型、妆容、鞋与轮廓）。

**音频设计：** BGM 至少一条全局轨；长片有明显间歇或转折时规划多段并各自定义范围。用大段旁白解说推进故事时以 narration 登记，定义语音特征、语调与准确脚本，并用覆盖范围限定在相关镜头内，不让旁白铺满全片变成有声书。

**信息与情绪的分工：** 能用画面与动作交代的信息，不要用旁白重复；旁白留给画面无法承载的背景、时间跨度与内心层次。情绪落点由表演与镜头承担，配乐只做托底。

## 六、Reference 路由

- 生成元素资产、角色参考图与镜头视频前（通道选择、版式、参考绑定、连贯性视频参考的取舍、降级），读 `references/媒体生成.md`（read_skill(resource="references/媒体生成.md")）。
- 撰写元素提示词、视频提示词与旁白文本时（六条核心规则、参考图命名、四层顺序、多节拍写法、特殊标记、负面约束），读 `references/提示词写作.md`（read_skill(resource="references/提示词写作.md")）。
- 进入组装导出（组装前核对、镜头衔接、音画优先级、字幕安全区、导出基准）时，读 `references/剪辑交付.md`（read_skill(resource="references/剪辑交付.md")）。
