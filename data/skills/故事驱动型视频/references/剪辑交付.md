# 剪辑交付

## 组装前核对

- 逐镜头确认视频、元素绑定与音频层都已就绪；缺失资产先回补，不带缺口进入组装。
- 装配顺序按已确认的故事板时间轴执行，不自行调换镜头次序。

## 剪辑节奏与过渡

- 相邻镜头的连贯性以分镜设计为准，只保留有叙事动机的衔接——动作匹配、视线延续、声音桥。
- 长镜头内部的剪辑段落保持景别纯净；跨镜切点优先硬切，避免无动机的花哨转场。
- 台词说完保留落点停留，动作做完保留收势，不提前切。
- 相邻镜头若跳轴，插入正面或过肩过渡镜，不强行拼接。

## 音频混装

- 全局背景音轨贯穿全片；多段 BGM 按各自范围入轨，交叠处做交叉淡化。
- 旁白轨按覆盖范围限定在相关镜头内，不越界铺满全片。
- 对白、音效与音乐冲突处，按叙事优先级压低次要层次——永远让当前承载信息的那个声音清楚。
- 台词与音效已在视频轨内嵌，组装不重复叠加。

## 字幕

- 字幕在后期添加，组装阶段预留字幕安全区，避免压在人物面部与关键信息上。
- 视频提示词里已禁掉模型自带字幕，出现残留即判该镜需重生成，不靠遮盖处理。

## 常见失败与修复

| 现象 | 原因 | 修复方向 |
| --- | --- | --- |
| 镜头美但故事没推进 | 分镜缺少叙事职能 | 回改分镜，删掉或改写无职能镜头 |
| 成片像有声书 | 旁白承担了本该由画面交代的信息 | 削减旁白，把信息还给画面 |
| 节奏平或碎 | 长镜头内段落划分与叙事节拍不符 | 重排内部剪辑顺序 |
| 人物跨镜漂移 | 元素图未绑定或参考图未命名 | 补绑元素图并在提示词命名参考后重生成 |
| 出现自带音乐或字幕 | 视频提示词缺负面约束 | 补 no music、no subtitles 后重生成 |
| 旁白与台词撞车 | 覆盖范围重叠 | 错开排布或调整范围 |
| 单镜超时被截断 | 分镜时长超全局设置 | 拆镜后重生成，不靠裁切硬拼 |

## 导出基准

- 画幅与总时长遵循制片规格；分辨率与帧率继承全局预设。
- 导出前完整过一遍：镜头顺序、故事是否讲清、旁白是否越界、BGM 是否压过人声、字幕安全区是否留足、有无模型自带文字残留。
- 组装与导出由用户在工作台操作，本 Skill 逐步引导核对；导出前用 workflow_pause 请用户做最终确认。
