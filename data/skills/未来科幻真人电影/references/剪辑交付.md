# 剪辑交付

> 组装阶段只做段落装配、节奏、调色与声画氛围；段内节拍不拆成额外视频段落。

## 段落级剪辑

- 每个剧情段落对应一段成片，按已确认时间轴顺序装配；段内节拍不拆成额外视频段落。
- 保留段落末尾与下一段开头的动作、视线、光源、色彩或环境介质衔接，接不上就回到上一段末段描述里补衔接，不靠转场遮。
- 节奏以开场几秒的悬念与中近景人物信息为优先；宏大空间镜头只在建立深空尺度、巨构压迫、废墟孤立或异星生态未知感时使用。
- 转场以直接切换、动作匹配、光线延续或短暂环境声桥为主，避免没有叙事动机的快速特效。

## 统一调色

- 调色严格匹配已锁定风格：深空保持冷静、低噪、受控高反差与机械环境声；太空歌剧保持庄严阴影、低饱和巨构尺度与肃穆声场；废土保持去饱和暖黄、尘土连续性与粗粝风声；异星生态保持湿润反射、局部生物来源光与有机环境声；默认或自定义风格按已确认的全局规则执行。
- 全片只使用一套调色方向，不为单个段落单独调偏色，除非剧情明确发生地点或时代转换。
- **后期禁区（强制）**：不得额外加入霓虹紫、粉、洋红或高饱和蓝色光污染，不得加全息界面式特效、赛博义体视觉或雨夜街头氛围——否则会把锁定的未来科幻方向误剪成赛博朋克。
- 纯白底资产不参与调色参考；色板基准取自场景四视图与首个确认段落。

## 音频混音层级

- 每段 audio_layer 与段落一一对齐，音频条目数与段落数一致。
- 设计上优先环境声与音效；音乐确需存在时只作氛围层，与对白冲突的层次主动压低。
- 对白为叙事主力时，环境声与音效让出频段，保证字字清楚。
- 环境声的物理来源与本段光线的物理来源保持同一空间逻辑——光线从哪来，声音就该从哪个方向与距离来。
- 独立 audio_layer 的情绪与节奏服务叙事，不拿视频生成时自带的音乐作为剪辑依据。

## 常见失败与修复

| 现象 | 原因 | 修复方向 |
| --- | --- | --- |
| 剪出来像赛博朋克 | 后期加了霓虹、洋红蓝光污染或全息界面 | 去掉后期光效，回到锁定风格的调色规则 |
| 段落之间跳变 | 段尾未做动作、视线、光线或环境介质衔接 | 回改上一段末段衔接描述后重新生成 |
| 场景四视图四格是四个不同场景 | 四视图生成不合格 | 判为无效资产重做，不拿它生成视频 |
| 场景里出现人物或人影 | 负向约束缺失 | 补空场景与禁止人物倒影影子的约束后重做 |
| 人物跨段变脸 | 人物资产未绑定或四视图不一致 | 补绑人物资产与四视图，重生成该段 |
| 画面出现动漫或游戏 CG 质感 | 负向约束不足或参考图风格污染 | 补写真人写实与杜绝 CG 动漫的约束，重生成 |
| 出现字幕或水印 | 视频提示词未明确禁止 | 强化禁止字幕、文字与水印，重新生成 |
| 生物发光变成城市霓虹 | 描述泛化、缺生物来源限定 | 限定生物部位、亮度、颜色与照亮范围后重生成 |
| 宏大空间镜头泛滥 | 全景与极远景被滥用 | 回改分镜，只在叙事需要处保留 |

## 导出基准

- 画幅、分辨率与帧率继承制片规格的全局预设，装配阶段不随意配置。
- 装配阶段只做段落拼接、节奏调整、音轨配比与轨道裁剪，不规划复杂后期图层合成与动态特效。
- 导出前完整过一遍：段落数与时长是否符合确认过的时间轴、段落衔接是否有跳变、全片调色是否一致、有无霓虹化倾向、对白是否清楚、字幕与水印是否残留。
