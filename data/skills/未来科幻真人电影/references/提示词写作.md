# 提示词写作

> 渠道与模型按全局设置；本分册只给结构与写法。

## 共同写作规则

- 用 Markdown 分级标题与固定模块顺序，不用表格；只输出当前阶段需要的内容。
- 所有描述以可见、可听、可执行的镜头信息为准，避免抽象心理判断。
- 场景单图的提示词正文不附负面提示词；工具名、元素标识与参考图占位符保持原样。
- 视觉提示词遵循固定顺序：主体或资产引用 → 场景与空间 → 可见动作与情绪 → 摄影机与构图 → 有来源的光线与物理介质 → 所选风格的色彩与材质 → 约束。
- 分镜与视频提示词都明确真人写实。不使用创作者、摄影师或某部影片的名字当执行指令，而是把意图拆成可见的空间、光线、构图与材质语言。
- 「8K」只可作为高细节电影质感的文字描述，不能覆盖生成工具实际设置的输出分辨率；实际分辨率遵从资产与视频生成规则。
- 除场景单图外，负向约束始终包含：禁止字幕、禁止水印、禁止文字、禁止卡通、禁止动漫、禁止游戏 CG、禁止塑料化 3D 渲染。视频提示词固定包含无背景音乐、无字幕；对白保持开放——剧情有对白时写出角色与逐字台词，并保留表演、口型与环境声的生成空间。

## 风格提示词库（只选一套）

按制片规格只嵌入一套已确认的风格描述，不要把四套全文叠加，否则光源、色彩与材质会互相矛盾。

- **硬核深空探索**：超写实电影质感，硬核太空探索纪实感，照片级真实与高细节。严谨航空工业设计、宇航级机械结构、高反差冷色布光、空间站内部实用点光源、真实物理反射与漫反射；高反光宇航服面料、划痕钛合金、清晰仪表屏幕与符合失重状态的微尘。构图锐利、噪点克制，深邃幽闭压迫。
- **史诗太空歌剧**：超写实电影质感，庄严的史诗科幻尺度。广袤空间、极简主义与粗野主义巨型建筑、电影级明暗对比与异星自然光下的肃穆阴影；风化石材、哑光厚重金属、防沙布料与干燥扬沙。大画幅般的稳定构图、轻微胶片颗粒与高动态范围，形成庄严静默的史诗感。
- **废土遗迹科幻**：超写实电影质感，粗粝的废土生存科幻感。被黄沙与植被吞噬的巨型科技遗迹、刺眼日光漫反射、沙尘中的可见光束与真实粒子；深度锈蚀钢铁、风化机械装甲、磨损皮革、干裂表面。去饱和暖黄、土褐与灰色，高动态范围，苍茫悲壮。
- **异星有机生态**：超写实电影质感，神秘而危险的异星生态探索感。有机体建筑、异星植物与真菌群落、湿润环境光、局部柔和且有生物来源的生物发光；黏滑组织、半透明叶脉、反光水滴、角质鳞片、真实折射与适度浅景深。色彩有层次但饱和度受控，生机与未知并存。
- **默认或用户自定义**：超写实真人电影质感，照片级真实材质细节，可信的做旧布料、金属、皮革、混凝土、尘土、水汽或其他剧情需要的物理介质，有来源的电影级光线、深邃黑位、受控饱和度与清晰叙事空间。

所有方向都追加禁区：不以霓虹灯、高饱和紫粉洋红蓝对比色、合成器波发光、全息投影、赛博义体、雨夜街道或无来源的彩色泛光构成未来感。异星生态的生物发光只描述生物部位、亮度、颜色与照亮范围，禁止泛化为城市霓虹。

## 人物资产提示词

- **无参考图的基础人物图**：用约三十个汉字交代外观，顺序是人物身份、脸部与发型、肤色、上身穿什么、裤子穿什么、头戴什么；不写鞋袜、腿部、全身动作或全身比例，裤装与头戴物只用于锁定造型，不要求完整入镜。描述后固定追加：（画幅遵循全局设置），半身视角，水平正面（正脸）视角，画面裁切至腰部，禁止全身构图，双手自然下垂且仅可在画面下缘局部出现，超写实人像摄影，8K 超高清，电影级柔和光影，真实皮肤质感，干净纯白色背景。未来城市、霓虹、复杂场景或额外风格一律排除。
- **有人物参考图时**：标明「用户已提供参考图，直接引用原图人物主体」，只描述需要保留的面部、发型、服装、身形比例等核心特征，不重新设计。若用户明确要求独立纯白底资产，再以原图为参考，仅移除环境背景并保留核心身份特征。
- **人物四视图**：无论有无参考图，都只用固定提示词，不添加任何风格描述——生成一张画幅遵循全局设置的超高清角色设计图（四视图），超逼真写实风格，表情自然，背景纯白。画面必须包含四个特定视角，从左往右依次为胸部以上近景、正面全身、全身侧面、背面全身；所有视角的角色形象、面部特征、服装细节与身体比例保持绝对一致，并与参考图完全契合。排版专业均衡，主体居中，构图饱满。
- **道具与其他单体主体**：纯白干净背景、单一完整主体、完整可见轮廓、真实材质、稳定比例；禁止场景背景、人物、人物痕迹、剧情事件、文字、水印与多余装饰。

## 场景单图提示词

- 一段连贯的正向描述，不设负面提示词或独立约束段。顺序：场景类别与尺度、平视机位、前景中景背景、天气或生态介质、氛围、空间结构、建筑或机械或有机或自然材质、可见且合理的光源、已锁定风格。
- 画面须清晰展示后续四视图要继承的空间核心、主体位置、比例、材质、色彩、天气、时间段与光源方向；以正向描述把单图定义为无人、静止且完整的场景环境，专注建筑、自然地貌、陈设、光线与物理介质。
- 把风格翻译成对应描述：深空写航空工业结构、实用点光源、冷色反射与失重条件；太空歌剧写巨型极简空间、庄严自然光与风化材质；废土写侵蚀遗迹、去饱和暖色、日光与沙尘；异星生态写有机结构、湿润介质与局部生物来源光。赛博朋克、霓虹、高饱和光污染、全息投影与赛博义体等词与视觉信号一律排除。

## 场景四视图提示词

- 横向画幅、干净的 2 行 2 列网格整齐四等分，每格都是独立的横向大全景。必须明确以已确认的场景单图为主要参考，四格继承其空间结构、主体位置、材质、天气、时间、色彩与光源方向；有用户场景参考图时同时保留其不可变更的核心特征。
- 先写场景类别、尺度、平视机位、前景中景背景、天气或生态介质、氛围、空间结构、建筑或机械或有机或自然材质、可见且合理的光源；风格继承本片已锁定的方向，不擅自替换为其他题材、赛博朋克或高饱和霓虹。
- 四格按固定顺序描述：一为正面中心线大全景（正对场景核心轴线、严格居中对称、尽量同时呈现顶面地面、完整空间层次、环境细节与深景深）；二以视图一的中心线为基准、摄像机位于左前方 45 度仍对准核心区域；三同基准、右前方 45 度；四从场景可进入的最深处或后侧沿中心轴向外拍摄，纯室外无内部可进入的自然景观则改为从远端向前景回望的中心大全景。
- 明确约束四格为同一时间、同一天气或生态状态、同一光源方向、同一空间结构、同一主体位置、同一比例、同一材质、同一色彩、同一美术风格；环境清晰、细节丰富、景深较深、光影自然、镜头稳定。正面图保持中心线构图与对称，两个 45 度视图及纵深或反向视图保持空间连贯、比例一致。
- 负向约束额外包含：空场景（禁止人物、人群、背影、剪影、人脸、肢体、人物倒影、人物影子、照片人物、屏幕人物、镜中人物、剧情事件或人物活动）、禁止倾斜构图、禁止透视畸变、禁止广角畸变、禁止变形扭曲、禁止鱼眼视角、禁止极端俯视仰视、禁止模糊、禁止浅景深、禁止边框、禁止标签、禁止界面元素、禁止杂乱元素。

## 分镜草稿图提示词

固定结构：按照下面的剧情脚本生成分镜图，采用至少 2×2 的网格分镜布局；默认 2×2、四个独立画格（画幅遵循全局设置），若要蒙太奇式的更多内部切分则用 3×2、六个相对更方的画格。画面不出现对白字幕。剧情：…… 风格要求：分镜绘图必须仅为黑白，粗糙铅笔线条、最小细节、快速手势绘图能量感、简单解剖结构构建、强烈的轮廓可读性，保持轻量动态未完成的质感，像早期手绘预览；图中标明分镜序号。

## 资产结合式分镜与视频提示词

- **资产结合式分镜**按固定结构写：分镜 N 与时间区间、段落主题、剧情、统一风格与质感。剧情必须严格复刻已确认段落的事件，写明人物与场景资产、环境、光影、动作、情绪、关键事件、特效与段尾衔接；不把一段拆成多个分镜。
- **视频提示词**按固定结构写：总时长、无背景音乐、无字幕、人物与场景引用（逐个占位符列出）、统一风格与质感、剧情、约束（杜绝游戏 CG 质感、杜绝动漫风格、杜绝 3D 渲染感）。剧情有对白时在剧情字段写出角色与逐字台词，不得写成「无对白」。若用了分镜草稿图，在引用行注明它是分镜图参考、按画格顺序执行，但仍以人物与已确认的场景四视图维持身份和空间一致性。
- 每段只写所选风格允许的一套光线、色彩、空间与材质规则。只有镜头实际可见时才描述光束、反射、扬沙、失重微尘、漂浮物或生物发光；不以赛博朋克视觉替代叙事。

## 固定尾部规则

- 所有视频提示词末尾包含：无背景音乐、无字幕、禁止文字与水印、杜绝游戏 CG 与动漫与 3D 渲染感。
- 不为模型情绪加抽象注解（「绝望感」「史诗感」这类词不进提示词），改写成可见的光线、空间比例、材质与动作。
- 不依赖绝对时间戳描述节奏，改用速度与力度词。
