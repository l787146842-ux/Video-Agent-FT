# 剪辑交付

> 组装阶段只做时间线层面的事：切点、转场、音画对齐、电平。风格化的分工按锁定的子风格走。

## 总基调

- 全片保持慢节奏叙事。每个切点前后留出静止画面让画面呼吸，快速闪切不在口径内。
- 剪辑必须服从制片规格里锁定的子风格，切换节奏与转场手段不得混用多套子风格的语言。

## 四种子风格各自的剪辑律动

- **华语家庭伦理**：极其克制的机位切换，保留高比例中景。对话或冲突爆发时在稳定的双人/多人中景与单人近景之间缓慢交替（AB 交替剪辑）；每个切点后拉长气口——动作停顿或视线避让的无声画面，用平稳框架与延长静滞承托家庭内部克制而汹涌的心理张力。
- **东方古典武侠**：在段落过渡与动作蓄势、收尾处精心编排空镜头，空镜头不必短，要等到画面内的意境动态（落叶飘零、水面泛漪、风穿竹林）完全舒展、淡化后才切下一镜。表现时空或梦境虚实转换时优先用极慢的淡入淡出，让武侠意境像水墨自然晕染。
- **西方古典悲剧**：剪辑极度向微相学特写倾斜。在面部微表情抽动、视线闪躲、眼中含泪的关键帧上做视觉延宕，延长特写展示时间，不急于切断，直到情绪压抑到极致。情感转折与命运判定时刻用冷酷突兀的硬切，不加任何过渡，形成逼仄窒息的宿命感。
- **现代视觉奇观**：剪辑服务于超现实奇观与对称秩序。对称构图或居中平衡镜头之间切换时保持水平视线绝对连续；主客观幻境交融处（现实残破小船切向浩瀚发光星海）用极柔和的叠化或跟随微光漫射的亮度变化过渡，做视听上的空间无缝滑动。

## 声音桥（J-cut 与 L-cut）

- **华语家庭伦理的听觉先行**：切入夹菜、倒茶等特写前一秒先起该镜的环境音——筷子轻碰瓷碗、热茶倾注茶杯的细流声，用琐碎声响打破上一镜的沉重静滞。
- **东方古典武侠的气韵重组**：切入竹林或山水空镜前先拉入风抚竹梢、隐约琴声；动作切分时把长剑微鸣的低沉余音延到下一镜开端，延展禅意余韵。
- **西方古典悲剧的宿命拉扯**：画面硬切后，把前一镜背景里的风雪呼啸或单簧管独奏的尾音延迟拖入下一镜，用声音的残留强化时空变迁下人物内心的冰冷与绝望。

## 音频混音层级

- **人声避让**：旁白或角色台词出现时，BGM 在人声起前开始平滑淡出并压低到垫乐电平；人声结束后用指数曲线缓慢自然恢复，不生硬忽大忽小。
- **人声轨不重叠**：旁白与镜头自带的角色对话不得在时间轴上重叠。分镜里两者同时存在时，用时间延伸、错开排布或局部微调保证同一时刻只有一种主导人声，字字清晰。
- **气口声学膨胀**：句与句之间超过两秒的留白里，把对应环境音（风声、雨声、柴火噼啪）平滑推高几个 dB 填补听觉真空，让寂静本身成为外化心理压抑的音效；下一句人声起前滑回原分贝。
- 关键情感冲突处可整段静音处理，以无声胜有声。
- 台词与音效已内嵌在视频轨，组装时不重复叠加同类音频。

## 常见失败与修复

| 现象 | 原因 | 修复方向 |
| --- | --- | --- |
| 出成分屏或四格画面 | 四宫格参考图泄露，提示词缺反泄露指令 | 补写反泄露指令后重生成，不靠剪辑遮盖 |
| 背景跳画 | 该镜未绑定场景元素或换了场景 ID | 追溯补全场景绑定，重生成该镜 |
| 道具变短变弯、手部与道具粘连 | 未绑定道具刚性设计图 | 补绑道具元素图，重生成该镜 |
| 人物无故张嘴乱说 | 无对白镜头未写静默指令 | 补静默指令，重生成该镜 |
| 出现幻觉分身或画面分裂 | shot 内多景别平铺在同一帧描述 | 拆成按剪辑顺序的时间段落，重写分镜 |
| 轻功动作塑料感 | 单镜承载了跨度过大的动作 | 分段拆镜，一镜只装一个动作阶段 |
| 角色开口但音色不一致 | 该镜未绑定角色音色资产 | 补绑定后重生成 |
| 台词与环境音打架 | 混音时未做人声避让 | 按避让包络重新处理电平 |
| 色彩跑偏 | 提示词未写胶片滤镜与色调意图 | 补色彩意图描述，重生成该镜 |

## 导出基准

- 导出比例与分辨率直接继承制片规格的全局预设，装配阶段不随意配置。
- 装配阶段只做基础编辑（拼接、速度调整、音轨配比、轨道裁剪），不规划复杂的后期图层合成与动态特效。
- 「现代视觉奇观」子风格在超分插帧后导出，装配时把音视频轨道对齐精度做到毫秒级，防止插帧引发音画不同步。
- 导出前完整过一遍：静默标记是否生效、旁白与台词是否真的没有重叠、BGM 是否压过人声、片中有无字幕残留。
