# 剧本生视频（需上传剧本）

> 调用规则：本 Skill 面向「已有剧本」的短视频工业化生成；未上传剧本时先引导上传或粘贴剧本正文。

<planner>
**完整视频的阶段逻辑和依赖关系：**
1. 通读用户上传或粘贴的剧本，用一句话总结并给出分析要点（read_uploaded_doc）。
2. 编写 `制片规格.md`（标题、类型、画幅、时长、视觉风格、语言；图像/视频生成渠道与分辨率遵循全局设置）→ document_write。先交互收集、后写文档：写入前必须先 workflow_pause 请求用户确认。建议条目：视频标题/视频类型/目标观众/输出语言/时长/画幅/叙事驱动/视觉风格/声音风格；渠道与分辨率等硬参数一律取顶部导航栏「全局设置」，不在交互中询问。
3. 第一拆：关键元素 → storyboard_create_group 建组、storyboard_add_draft 录入元素草稿（本步只创建关键元素分组：角色/场景/道具；分镜或音频分组排除在外）。
4. 关键元素出图 → image_generate（须在用户确认步骤3之后执行）。
5. 第二拆：分镜与音频层（须在用户确认步骤4的元素图像之后执行）→ 依次创建分镜分组与音频分组（storyboard_create_group / storyboard_add_draft）。
6. 分镜视频 Prompt Draft → 用 storyboard_patch_draft 把每个镜头的视频提示词写入对应草稿（target=all_shots 逐一处理）。
7. 每个镜头生成最终视频 → generate_video；严格参考该镜头的元素图像（步骤4）；须在用户确认步骤6之后执行。
8. 音频层（台词/BGM/旁白）由系统生成通道按故事板 audio_layers 配置产出，无需工具调用；生成前完成步骤5的音频层登记。
9. 所有资源就绪后进入最终剪辑与导出——由用户在工作台操作，Agent 引导即可（无对应工具调用）。

**依赖关系：** 2→1；3→1,2；4→3；5→3,4；6→5；7→4,6；8→5；9→7,8

**关键暂停点：** 每个阶段完成后必须暂停，等待用户确认再继续。
</planner>

<storyboard_key_elements>
**本节职责（强制基线）**：只创建关键元素（keyElement）分组，**分镜、音频分组一律排除在外**（创建或修改均排除）；角色描述须包含年龄/性别/外貌/发型/服装，场景描述须包含空间结构与氛围词。
</storyboard_key_elements>

<storyboard_shots>
**本节职责（强制基线）**：只创建分镜（shot）分组，分镜必须通过 sceneRefs 引用已登记的关键元素；单 shot 时长遵循全局设置中的时长参数，出场人物 ≤ 3 人。
</storyboard_shots>

<storyboard_audio>
**本节职责（强制基线）**：只创建音频（audio）分组，**关键元素与分镜分组一律排除在外**（创建或修改均排除）；为台词、BGM、旁白建立独立 audio_layer。
</storyboard_audio>

<generate_video>
**制作参数基准：** 出图/出视频渠道与分辨率一律遵循顶部导航栏「全局设置」，单镜头时长上限遵循全局设置中的时长参数；元素图须参考角色三视图/场景四视图，视频须引用对应元素图像。
</generate_video>

<write_media_prompt>
**强制基线、适用于所有prompt编写情况：提示词须包含景别、运镜、光线与材质锚点，禁止匿名空镜与平铺直叙。
</write_media_prompt>

<video_assembler>
按分镜和时间轴顺序组装所有镜头、旁白音轨和BGM；当剪辑就绪后，引导用户导出。
</video_assembler>
