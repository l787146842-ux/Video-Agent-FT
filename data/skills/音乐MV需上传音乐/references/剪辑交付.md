# 剪辑交付

> 合成阶段的核心只有一条：画面服从音乐。先对齐时间，再谈节奏。

## 音轨对齐（第一步）

- 静音视频轨，把上传的音乐作为唯一时间基准；按每个镜头的时间戳（以及用到的歌词时间点）把各镜对齐到音乐时间线。
- 分镜时间线按逐行或逐短语的起止时间构建时，镜头窗口前后保留缓冲，让可用窗口落在第一个歌词时间戳之前、最后一个歌词时间戳之后的质量区间内。
- 缓冲与相邻镜头重叠时：合并两镜、在自然短语边界重新分割，或在生成前调整镜头边界；无论怎么处理，每镜内的歌词单元必须完整。

## 口型同步片段的保护

- 用音频驱动通道生成的演唱镜头，不得更改播放速度，也不得改动时间戳。速度一变，口型立刻与音频脱节。
- 两个口型同步片段之间若出现没有可用素材的空白，用现有素材里最合适的叙事或表演剪辑填补，不要用变速去凑时长。

## 剪辑节奏与过渡

- 切点优先落在音乐的重拍与歌词单元的边界上，其次落在短语的自然停顿处；不为凑分镜在歌词中间硬切。
- 叙事镜头与演唱镜头交替出现时，切换要跟随歌曲结构——主歌用叙事铺陈，副歌与说唱段给演唱镜头，桥接处可做情绪过渡。
- 相邻镜头若跳轴，插入正面或过肩过渡镜，不硬拼。
- 转场以硬切为主；确需软化时用短叠化，避免花哨转场打断音乐节奏。

## 音频混音层级

- 音乐是主轨，人声（若有旁白或独立人声轨）在其之上；演唱人声已经内嵌在口型同步片段里，不额外叠加同类音频，避免双重人声。
- 若另建了旁白轨，旁白出现处把音乐适当下压，旁白结束后平滑恢复。
- 音效只在必要时点缀，不与人声和主旋律抢频段。
- 合成前确认全片音量以音乐为基准统一，不出现某几段明显更响或更轻。

## 常见失败与修复

| 现象 | 原因 | 修复方向 |
| --- | --- | --- |
| 口型与歌词对不上 | 视频被变速或时间戳被改动 | 恢复原速原位，重排时间线 |
| 画面切点切断了歌词 | 分镜时间窗落在歌词中间 | 在自然短语边界重分割镜头，必要时补生成 |
| 镜头衔接跳变 | 关键帧未参考同组先前帧 | 补绑更相近的关键帧后重出 |
| 人物跨镜漂移 | 元素图像未绑定三视图或视角不全 | 补三视图与元素绑定，重生成该镜 |
| 某段没有可用素材 | 分镜检查遗漏 | 用现有素材里最合适的叙事镜头填补，必要时补生成 |
| 出现自带音乐 | 视频提示词未写 no music | 补写后重新生成该镜 |
| 画面出现字幕 | 未写 no subtitles | 补写后重新生成 |
| 全片音量忽大忽小 | 未以音乐为基准统合 | 按音乐轨重做整体电平 |

## 导出基准

- 画幅、分辨率与帧率继承全局预设；音乐轨不做二次压缩，导出时确认采样率与声道数与上传文件一致。
- 导出前完整过一遍：每句歌词是否都落在完整镜头内、口型片段是否被变速、旁白与演唱是否撞在同一时刻、音量是否统一、片中有无字幕残留。
