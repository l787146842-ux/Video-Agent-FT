# 剪辑交付

## 剪辑节奏与过渡

- 按故事板与时间轴顺序组装所有镜头、旁白轨与 BGM，不自行调换镜头次序。
- 节奏由叙事决定：信息密度高的段落切点紧，情绪与留白段落给足呼吸。
- 同一物理空间内的相邻镜头优先硬切；跨空间切换可用短叠化，避免滥用转场。
- 相邻镜头若跳轴，插入正面或过肩过渡镜，不强行拼接。

## 视频层音频处理

- 如果该镜没有台词或旁白，在剪辑中把该镜头视频层的嵌入音频静音，只依赖音频层里按设计使用的 BGM 与音效；否则视频生成的音频会与混音冲突。
- 有内嵌台词的镜头保留其音轨，不重复叠加同类音频。
- 静音操作逐镜检查，不要整轨一刀切。

## 音频混音层级

- BGM 低于人声与旁白，作底层垫乐；情绪高潮段可适当提升。
- 多段 BGM 按各自定义的范围入轨，交叠处做交叉淡化。
- 旁白限定在相关镜头内，与台词不得在同一时刻重叠。
- 音效紧贴对应动作，不与人声抢频段。

## 常见失败与修复

| 现象 | 原因 | 修复方向 |
| --- | --- | --- |
| 关键帧丢掉了元素风格 | 关键帧提示词写得太长，被全量重绘 | 缩短到只留路由与故事板要求，重新精修 |
| 元素风格跨批次漂移 | 风格参考代码遗漏或前后不一致 | 统一代码清单后重出 |
| 视频层音频与混音打架 | 无对白镜头未静音视频层 | 逐镜检查并静音 |
| 人物跨镜漂移 | 元素图未绑定或视频提示词未命名参考 | 补绑元素图、为参考图命名角色后重生成 |
| 出现自带音乐或字幕 | 视频提示词缺负面约束 | 补 no music、no subtitles 后重生成 |
| 画面出现无关文字 | 画面内文字未用引号限定或未禁止 | 限定确切文本或改为排除，重生成 |
| 叙事与画面脱节 | 镜头视觉选择无叙事功能 | 回改分镜，让每个视觉选择对应一个叙事任务 |

## 导出基准

- 画幅、分辨率与帧率继承全局预设。
- 导出前完整过一遍：镜头顺序、视频层静音是否逐镜正确、多段 BGM 交叠是否平滑、旁白与台词是否清楚分层、片中有无字幕与文字残留。
- 交付时说明本项目使用的风格参考代码清单，便于后续续做保持同一外观。
