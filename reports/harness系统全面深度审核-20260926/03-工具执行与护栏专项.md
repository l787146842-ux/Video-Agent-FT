## 三、缺陷与风险

> 每条给出严重度、`file.py:line`、实码引用。架构级问题优先。

### D1 【blocker】`platform.prompt_write` 闸已空转：唯一「硬伤生产者」为空，与宪法 §2.1 正面冲突

`prompt_gates.validate_prompt_write` 全文只有 `soft.append`，**没有任何 `hard.append`**（AST/grep 双向确证：`hard` 出现在 `prompt_gates.py:199/201/202/208/211/228/229`，全部为声明、返回或读取，无一处写入）：

```
prompt_gates.py:208|         hard: List[str] = []
prompt_gates.py:228|     ok = not hard
prompt_gates.py:229|     return ok, hard, soft
```

于是 `ok` 恒为 `True`，`guard_pipeline.evaluate_prompt_write` 的三条拒收分支**永不可达**：

```
guard_pipeline.py:118|     ok, hard, _soft = prompt_gates.validate_prompt_write(
guard_pipeline.py:137|     if mode != "strict":
guard_pipeline.py:140|     out.ok = False
guard_pipeline.py:142|     out.reject_message = prompt_gates.format_gate_errors(hard)
```

## 四、正向设计建议

> 逐条对应缺陷，给出**目标抽象**（应存在的位置 + 对外接口），不是补丁。

### S1 → D1 / D2 / D11：把闸机做成「规则即数据 + 判定即注册」的显式管线

**目标抽象**：`core/guard_pipeline.py` 内定义

```python
@dataclass(frozen=True)
class GateStage(Enum):
    INPUT = "input"; TOOL_INPUT = "tool_input"; TOOL_OUTPUT = "tool_output"; OUTPUT = "output"

@dataclass(frozen=True)
class GateSpec:
    rule_id: str                 # 必须存在于 gate_registry.GATE_RULES
    stage: GateStage
    applies: Callable[[GateCall], bool]      # 纯谓词：声明轴（risk / provider_kind / 工具名集合来源化）
    evaluate: Callable[[GateCall], GateVerdict]   # 唯一判定体
    message_sections: Tuple[str, ...]        # 必须 ⊆ messages.md 且双向可查
```

`GuardPipeline(stages: Sequence[GateSpec])` 暴露 `async def run(call: GateCall) -> PipelineOutcome`；`GateCall` 携带 `tool_name / args / state / consent / stage_ctx`，`PipelineOutcome` 携带 `verdicts: List[GateVerdict]`（**不再压成裸字符串**）。

关键不变式（由 `tests/unit/test_guard_pipeline_contract.py` 机器钉死）：
- 每个 `GateSpec.rule_id ∈ GATE_RULES`，且每个 `GATE_RULES` 条目必须有恰好一个 `GateSpec`（**双向**，防 D3 式孤儿）；
- 每个非空 `message_sections` 必须有 ≥1 个 `evaluate` 分支可达（用参数化用例覆盖）；
- `audit_verdicts` 由 `GuardPipeline.run` **统一**调用，`evaluate_*` 不得自审（消除 D10 的接线不一致）；
- `GateVerdict` 必须原样上抛到 `FCExecuteResult.warnings` 的**结构化**版本，供前端 chips 渲染（对齐 §2.4）。

`fc_gates` 退化为「构造 `GateCall` 的适配器」；`card_media_gate` / `structure_integrity_gate` 迁出为独立 `evaluate_*` 实现体并登记 `rule_id`。
