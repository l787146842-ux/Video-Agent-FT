def find_group(state, group_id, group_type="", selected_draft_id="", selected_type=""):
    categories = categories_for_type(group_type)
    for cat_key in categories:                       # ① 先按真实 id 找
        for group in state.get(cat_key, []):
            if group.get("id") == group_id: return group
    if group_id in ("current", ""):                  # ② "current" 兜底
        if selected_draft_id:                        #   ②a 前端选中草稿优先

            if found: return found[0]

| 步 | 环节 | 事实 |
|---|---|---|
| 1 | 模型入参 | `{"group_id": "current", "draft": {...}}`，**未传 `group_type`**（seq=140/146 原文） |

| 4 | 兜底选择 | 走 ②b：`for cat_key in categories: if groups: return groups[0]` → **`keyElements[0]`** |
| 5 | 落到谁 | `keyElements[0]` = **`Element_主要角色`**（`ke-1790091831-22a4f79b`，5 张角色卡） |

- （模型 seq=157 猜的「因为它是第一个有内容的组」**只对了一半**——真正决定性的是**类目顺序**，
